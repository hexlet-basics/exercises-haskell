В этом уроке мы изучим чистые функции в Haskell. Разберём определение функции, её аргумент и запись типа входного и выходного значения. Мы научимся получать текстовый результат и применять одну функцию к разным строкам.

## Аргумент и результат

Чистая функция вычисляет результат по переданным ей аргументам. При одинаковых аргументах она даёт одинаковый результат и не меняет внешнее состояние программы. Чтобы понять такой вызов, достаточно знать определение функции и её входные значения. Значение из файла или текущее время пришлось бы явно передать в качестве аргумента.

Например, функция обработки текста может получить строку и построить из неё новую строку. Она возвращает вычисленное значение. Выводить его на экран, сохранять или использовать в дальнейшем вычислении будет тот код, которому нужен результат. Само получение строки вывода на экран не выполняет.

Схема показывает границы такого вычисления. Входная строка попадает в функцию, а результат становится доступен снаружи.

```text
аргумент             чистая функция             результат
"go"         ---->   повторить текст    ---->   "gogo"
```

На схеме у функции один вход и один результат. Одинаковая строка `"go"` даёт строку `"gogo"` при каждом применении. Для другого аргумента функция выполнит то же преобразование над другим текстом.

## Определение функции

Пусть для короткой надписи нужно повторить переданный текст дважды без разделителя. Назовём функцию `duplicate`, а входной текст обозначим именем `text`. Файл с определением выглядит так.

```haskell
module Solution where

duplicate :: String -> String
duplicate text = text ++ text
```

В этом коде строка `module Solution where` задаёт имя учебного файла как модуля `Solution`. Она уже находится в каркасе упражнения. Подробно устройство модулей разбирается дальше по курсу.

Определение функции находится в строке `duplicate text = text ++ text`. Слева от `=` стоят имя функции `duplicate` и имя аргумента `text`. Справа находится выражение, задающее результат. При применении функции имя `text` обозначает переданную строку. Здесь оно используется дважды, поэтому входной текст повторяется в результате.

Оператор `++` соединяет строки, сохраняя их символы и порядок. Он не добавляет пробел между частями. У строки `"go"` есть два символа, а у результата `"gogo"` их четыре. Литерал строки записывается в двойных кавычках. Сами кавычки обозначают границы текста и в его содержимое не входят.

Над определением находится сигнатура `duplicate :: String -> String`. Сигнатура описывает тип функции. Здесь `String` называет тип строкового значения, а стрелка разделяет тип аргумента и тип результата. Запись читается как «функция принимает строку и возвращает строку». Имя `duplicate` в сигнатуре и определении совпадает.

## Применение функции

Для применения функции в Haskell после её имени через пробел записывается аргумент. Поэтому выражение `duplicate "go"` обозначает результат обработки строки `"go"`. Скобки вокруг единственного строкового аргумента здесь не нужны. Применение функции связывает сильнее операторов, поэтому `duplicate "ha" ++ "!"` читается как `(duplicate "ha") ++ "!"` и даёт `"haha!"`. Чтобы передать составное выражение как один аргумент, его заключают в скобки, например `duplicate ("ha" ++ "!")`.

Небольшая подстановка показывает, как определение связано с результатом этого выражения.

```text
duplicate "go"
       |
       v
"go" ++ "go"
       |
       v
    "gogo"
```

В этой схеме обе записи `text` заменены одним переданным значением `"go"`. После соединения строк получаем `"gogo"`. Для выражения `duplicate "ha"` результатом будет `"haha"`, а для `duplicate ""` результатом будет пустая строка `""`.

Значение, которое вернула чистая функция, можно передать другому вычислению. Так постепенно строится программа из небольших определений с явными входами и результатами. В упражнении мы напишем собственную функцию, которая формирует строку по переданному имени.
