В этом уроке мы изучим числовые вычисления в Haskell. Разберём арифметические операции, получение целой части частного и остатка от деления. Мы научимся выбирать способ деления и преобразовывать целое значение для вычислений с дробным результатом.

Сигнатура числовой функции определяет, какие значения она принимает и возвращает. Для количества предметов удобно использовать `Integer`. При вычислении отношения величин может понадобиться дробный результат, для которого в наших примерах используется `Double`. Способ деления выбирается с учётом этой задачи и типов значений.

## Арифметические выражения

Операторы `+`, `-` и `*` записываются между двумя числами. Умножение имеет более высокий приоритет, чем сложение и вычитание. Скобки позволяют явно выделить часть выражения, которую нужно получить перед другой операцией.

Например, для прямоугольной рамки известны ширина и высота в сантиметрах. Длина её контура равна удвоенной сумме этих размеров. Функция принимает два целых размера и возвращает целую длину.

```haskell
frameLength :: Integer -> Integer -> Integer
frameLength width height = 2 * (width + height)
```

В этом коде выражение `width + height` находится в скобках, и его результат умножается на `2`. Применение `frameLength 7 4` даёт `22`. Без скобок выражение `2 * width + height` при тех же аргументах дало бы `18`, потому что сначала выполняется умножение.

Сложение и вычитание также образуют обычное выражение результата. В программе учёта запасов можно описать поступление двенадцати предметов и выдачу пяти предметов.

```haskell
updatedStock :: Integer -> Integer
updatedStock stock = stock + 12 - 5
```

В этом коде `updatedStock 13` возвращает `20`. Аргумент `stock` сохраняет своё значение. Функция вычисляет новое количество, которое можно передать в другое вычисление.

## Целая часть частного и остаток

Для целых чисел доступны функции `div` и `mod`. Они принимают делимое и делитель. В примерах с неотрицательным делимым и положительным делителем `div` даёт количество полных частей, а `mod` оставшуюся часть.

Например, в одну коробку помещается шесть предметов. Число коробок должно покрывать все предметы, даже если последняя коробка заполнена частично. Прибавление пяти перед делением округляет количество коробок вверх для неотрицательного входа.

```haskell
boxCount :: Integer -> Integer
boxCount items = div (items + 5) 6
```

В этом коде для `boxCount 14` получаем `3`, поскольку `div 19 6` даёт `3`. При точном заполнении двух коробок `boxCount 12` даёт `2`. Для пустого заказа `boxCount 0` возвращает `0`.

Остаток позволяет повторять позиции по кругу. Пусть в недельном расписании дни имеют номера от нуля до шести. После позиции шесть нужно снова получить ноль.

```haskell
nextDay :: Integer -> Integer
nextDay day = mod (day + 1) 7
```

В этом коде `nextDay 3` даёт `4`, а `nextDay 6` даёт `0`. Если делимое делится нацело, остаток равен нулю. Именно поэтому `mod 7 7` возвращает начало недельного круга.

Во всех этих примерах делитель положителен. Деление целого числа на ноль приводит к ошибке при вычислении результата. Для практики допустимые входы задаются так, чтобы это исключить. Правила для отрицательных аргументов потребуют отдельного разбора.

## Деление с дробным результатом

Оператор `/` используется для дробных числовых типов. Например, функция с аргументом и результатом `Double` может вычислить половину величины.

```haskell
half :: Double -> Double
half amount = amount / 2.0
```

В этом коде `half 7.0` даёт `3.5`. Сигнатура связывает аргумент и результат с типом `Double`, поэтому число `2.0` в этом выражении тоже используется как `Double`. Значения `Double` хранят приближённое представление дробных чисел. Для точного счёта неделимых единиц можно сохранять величины в `Integer`.

Отрицательный числовой аргумент нужно заключать в скобки. Например, `half (-7.0)` даёт `-3.5`. Применение функции связывает сильнее операторов, поэтому минус без скобок разбирается как вычитание. Следующая запись намеренно неверна.

<!-- lint-code-blocks: skip — без скобок минус задаёт вычитание из функции half -->

```text
half -7.0
```

GHC 9.0.2 отклоняет это выражение как попытку числовой операции над функцией. Фрагмент его фактической диагностики показывает, как прочитана запись.

```text
In the expression: half - 7.0
```

Левым операндом вычитания здесь становится сама функция `half`. Для передачи отрицательного числа аргументом нужны скобки в записи `half (-7.0)`. Они сохраняют знак минуса внутри аргумента.

Значение типа `Integer` не преобразуется в `Double` автоматически. Если сумма четырёх измерений задана целым числом, её нельзя прямо использовать в делении с ожидаемым дробным результатом. Следующее определение намеренно неверно.

<!-- lint-code-blocks: skip — целый аргумент не преобразуется в Double автоматически -->

```text
average :: Integer -> Double
average total = total / 4.0
```

В этом примере тип `total` остаётся `Integer`, а сигнатура требует результат `Double`. Для такого вычисления нужно явно преобразовать целое значение через `fromIntegral`. Контекст выражения задаёт числовой тип результата преобразования.

Для неверного определения компилятор показывает несовместимость результата.

```text
Couldn't match expected type ‘Double’ with actual type ‘Integer’
```

В сообщении видны оба типа. Одной записи `Double` в сигнатуре недостаточно для преобразования целого аргумента; правильное определение явно вызывает `fromIntegral` перед делением.

```haskell
average :: Integer -> Double
average total = fromIntegral total / 4.0
```

В этом коде `fromIntegral total` используется как `Double`, что определяется результатом функции и делением через `/`. Применение `average 15` даёт `3.75`. Сама `fromIntegral` поддерживает разные числовые типы, а здесь показано её конкретное применение для перехода от `Integer` к `Double`.
