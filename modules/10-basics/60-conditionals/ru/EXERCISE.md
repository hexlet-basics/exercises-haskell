Реализуйте функцию `deliveryCost :: Integer -> Bool -> Integer`, которая определяет стоимость доставки заказа.

Первый аргумент `orderTotal` содержит сумму заказа в рублях, целое число от `0` до `1000000000` включительно. Второй аргумент `hasSubscription` равен `True`, если у покупателя есть подписка с бесплатной доставкой.

Доставка бесплатна при сумме заказа от `5000` рублей включительно или при наличии подписки. В остальных случаях её стоимость составляет `290` рублей. Верните стоимость как `Integer`, без вывода на экран.

Проверьте границу бесплатной доставки по примерам.

| Применение | Результат |
| --- | --- |
| `deliveryCost 2000 False` | `290` |
| `deliveryCost 4999 False` | `290` |
| `deliveryCost 5000 False` | `0` |
| `deliveryCost 2000 True` | `0` |
| `deliveryCost 0 True` | `0` |

Используйте условное выражение `if then else`. В обеих ветвях должен получаться числовой результат.
