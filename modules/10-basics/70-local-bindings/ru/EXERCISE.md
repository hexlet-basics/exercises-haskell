Реализуйте функцию `orderPrice` с сигнатурой `Integer -> Integer -> Bool -> Integer`. Она принимает количество товаров, цену одного товара и признак подарочной упаковки. Функция возвращает полную стоимость заказа.

В этой учебной модели действуют следующие правила.

- Стоимость товаров равна количеству, умноженному на цену одного товара.
- Подарочная упаковка стоит `40`, когда третий аргумент равен `True`. Для `False` стоимость упаковки равна нулю.
- Доставка стоит `150`, если стоимость самих товаров меньше `2000`. При стоимости товаров от `2000` доставка бесплатна.
- Полная стоимость складывается из стоимости товаров, упаковки и доставки. Упаковка не учитывается при проверке порога бесплатной доставки.

Все суммы заданы в условных денежных единицах. Количество находится в диапазоне от `1` до `1000`, цена одного товара от `0` до `100000`. Другие входы обрабатывать не требуется.

Дайте имена промежуточным суммам с помощью `let ... in` или `where`. Используйте изученное условное выражение для выбора стоимости упаковки и доставки.

Примеры показывают полную стоимость для разных заказов.

```haskell
orderPrice 3 400 False -- 1350
orderPrice 3 400 True  -- 1390
orderPrice 5 400 False -- 2000
orderPrice 1 1999 True -- 2189
```

В последнем примере товары стоят `1999`, поэтому доставка остаётся платной. Стоимость упаковки не меняет это решение.
