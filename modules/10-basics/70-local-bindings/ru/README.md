В этом уроке мы изучим локальные определения в Haskell. Разберём запись `let ... in`, определения через `where` и область видимости имён. Мы научимся выделять промежуточные вычисления и небольшие вспомогательные функции внутри одного определения.

Длинное выражение бывает трудно проверить по смыслу. Если его части имеют собственное назначение, им можно дать имена рядом с местом использования. Локальное определение связывает такое имя с выражением внутри ограниченной части программы. За её пределами имя недоступно.

## Выражение let

Запись `let ... in ...` состоит из определений после `let` и выражения результата после `in`. В выражении после `in` доступны введённые имена. Всё выражение `let` имеет значение, поэтому его можно использовать как результат функции или как часть другого вычисления.

Пусть поездка начинается в заданную минуту дня. Она включает время движения и остановку длительностью десять минут. Чтобы назвать обе составляющие, запишем функцию расчёта минуты прибытия через локальные определения.

```haskell
arrivalMinute :: Integer -> Integer -> Integer
arrivalMinute start movingMinutes =
  let stopMinutes = 10
      duration = movingMinutes + stopMinutes
  in start + duration
```

В этом коде `stopMinutes` обозначает длительность остановки, а `duration` полную длительность поездки. Для `arrivalMinute 480 45` получаем `535`, поскольку к началу поездки прибавляются 45 минут движения и 10 минут остановки.

Определения `stopMinutes` и `duration` начинаются в одной колонке. Так отступы показывают, что оба имени относятся к одному набору определений после `let`. Строка с `in` завершает этот набор и задаёт выражение результата.

Зависимости между значениями можно представить небольшой схемой.

```text
movingMinutes   stopMinutes
       \         /
         duration       start
              \         /
              результат
```

На схеме `duration` зависит от времени движения и остановки. Итоговое значение дополнительно зависит от `start`. Определения описывают эти связи, поэтому порядок строк с локальными именами не задаёт последовательное изменение состояния.

## Определения where

Для вспомогательных определений всей функции удобна запись `where`. Выражение результата располагается перед `where`, а локальные имена и их выражения после него. Рассмотрим тот же расчёт с другим расположением определений.

```haskell
arrivalWithStop :: Integer -> Integer -> Integer
arrivalWithStop start movingMinutes = start + duration
  where
    stopMinutes = 10
    duration = movingMinutes + stopMinutes
```

В этом коде `duration` доступно в выражении `start + duration`. Локальное определение `duration` использует аргумент функции `movingMinutes` и соседнее имя `stopMinutes`. Оба определения после `where` имеют одинаковый отступ. Снаружи функции обратиться к её `duration` по этому имени нельзя.

Выбор между `let` и `where` зависит от нужной области видимости. `let` позволяет ввести имя прямо внутри отдельного выражения, например одной ветви `if`. Определения через `where` относятся к окружающему определению функции. В показанном расчёте подходят обе записи, и результат остаётся одинаковым.

## Локальная вспомогательная функция

Внутри `let` или `where` можно определить функцию. Её имя доступно в той же локальной области. Это помогает назвать повторяющееся правило, которое нужно только одному вычислению.

Например, учебная модель маршрута содержит два участка. На каждый километр отводится две минуты, а подготовка перед каждым участком занимает пять минут. Для расчёта одного участка введём локальную функцию `legMinutes`.

```haskell
tripMinutes :: Integer -> Integer -> Integer
tripMinutes firstDistance secondDistance =
  legMinutes firstDistance + legMinutes secondDistance
  where
    legMinutes :: Integer -> Integer
    legMinutes distance = distance * 2 + 5
```

В этой функции `legMinutes` принимает расстояние одного участка. Применение `tripMinutes 3 7` даёт `30`, потому что `legMinutes 3` равно `11`, а `legMinutes 7` равно `19`. Сигнатура локальной функции записывается рядом с её определением по тем же правилам, что и сигнатура функции на уровне файла.

## Затенение имени

Локальное имя может совпасть с внешним. Тогда внутри своей области видимости оно обозначает локальное значение. Такое совпадение называется затенением. Внешнее определение при этом сохраняется.

Следующий пример использует две разные длительности остановки с одним именем.

```haskell
stopMinutes :: Integer
stopMinutes = 10

shortTrip :: Integer -> Integer
shortTrip movingMinutes =
  (let stopMinutes = 3 in movingMinutes + stopMinutes) + stopMinutes
```

Здесь внутри скобок `stopMinutes` равно `3`. Последнее `stopMinutes` находится за пределами выражения `let` и обозначает внешнее значение `10`. Поэтому `shortTrip 20` даёт `33`. Затенение помогает понять границы доступности имён, но разные понятия обычно проще назвать по-разному, чтобы читателю не приходилось отслеживать совпадения.
