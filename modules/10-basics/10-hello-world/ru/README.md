Haskell относится к функциональным языкам программирования. На нём мы описываем вычисления через функции, которые получают данные и возвращают результат. В этом курсе мы освоим такой способ построения программ и научимся записывать небольшие вычисления на Haskell.

Курс рассчитан на человека, который уже программирует на любом языке. Достаточно уметь пользоваться функциями, условиями и последовательностями данных. Функциональное программирование, рекурсию и систему типов Haskell мы будем изучать с начала. Для выполнения упражнений хватит редактора на этой странице, устанавливать инструменты на компьютер не потребуется.

## Как устроены вычисления

Допустим, программе нужно подготовить текст уведомления. Само составление текста можно описать функцией с явными входными данными. Если передать ей те же данные, результат вычисления останется тем же. Такую функцию называют чистой. Отдельное действие отправляет готовый текст на экран или передаёт его другой системе.

Это разделение помогает проверить вычисление само по себе. Например, мы проверяем правило формирования уведомления на разных именах без отправки настоящих сообщений. При изменении правила мы можем заново вычислить результат для тех же входных данных и сравнить его с ожидаемым. В Haskell работа с внешним миром выделена в действия, которые мы подробно изучим к концу курса.

Обычные данные в Haskell неизменяемы. При преобразовании мы описываем новое значение, а исходное сохраняется. Например, функция может получить последовательность показаний и вернуть подходящие значения. Нам предстоит научиться описывать такие преобразования и соединять их в более крупные вычисления.

## Как выглядит программа

Небольшая программа ниже готовит приветствие для одного человека и выводит его на экран. Пока посмотрим на неё целиком, без разбора всех конструкций. Определения функций, их типы и правила применения получат отдельные объяснения по ходу курса.

```haskell
module Solution where

message :: String -> String
message name = "Welcome, " ++ name ++ "!"

main :: IO ()
main = putStrLn (message "Ada")
```

В этой программе `message` составляет текст из переданного имени. Действие `main` описывает вывод готового текста. При запуске программа печатает одну строку.

```text
Welcome, Ada!
```

На схеме видно, как данные связывают составление текста с его выводом.

```text
Имя "Ada"
    |
    v
Чистая функция message
    |
    v
Текст "Welcome, Ada!"
    |
    v
Действие вывода на экран
```

На этой схеме функция получает имя и создаёт текст. Действие вывода использует этот текст для взаимодействия с внешним миром. Так мы сможем отдельно написать и проверить функцию, которая выполняет расчёт, а затем использовать результат в программе с вводом и выводом.

## Как построен курс

Сначала мы освоим выражения, определения функций и запись типов. Затем разберём списки и сопоставление с образцом, чтобы извлекать данные по их форме. Рекурсия научит нас описывать обработку последовательности через меньшую часть той же задачи, даже если прежде мы не пользовались этим приёмом.

После этого мы научимся передавать функции как обычные значения. На этой основе разберём частичное применение, каррирование, композицию и преобразование списков.

Собственные типы данных помогут описывать варианты результата, включая отсутствие значения и ожидаемый отказ. Мы подключим модули стандартной библиотеки и научимся читать сигнатуры с классами типов. Ближе к концу курса изучим вычисление по требованию и свяжем чистые функции с консольным вводом и выводом.

В упражнениях будут самостоятельные небольшие задачи с автоматическими проверками. Устанавливать пакеты и создавать приложение с нуля для каждой задачи не потребуется.

## Практика в тренажёре

В упражнении этого урока мы дополним готовый вызов текстом в двойных кавычках. Строка `module Solution where` обозначает учебный файл. Сигнатура `main :: IO ()` описывает действие с внешним миром, у которого нет входных аргументов и полезного возвращаемого значения.

Функция `putStrLn` описывает вывод переданного текста с переводом строки. Текст между маркерами мы записываем с отступом в два пробела, как в каркасе. Общее правило продолжения определений мы разберём при знакомстве с выражениями.
