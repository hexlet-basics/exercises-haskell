Реализуйте функцию `humidityStatus :: Integer -> String`, которая возвращает категорию показания учебного датчика влажности.

Функция получает целый процент влажности от `0` до `100` включительно. Категории определяются следующими правилами.

| Показание | Результат |
| --- | --- |
| Меньше `30` | `"dry"` |
| От `30` до `70` включительно | `"normal"` |
| Больше `70` | `"wet"` |

Например, `humidityStatus 29` возвращает `"dry"`, а `humidityStatus 30` возвращает `"normal"`. Значение `70` относится к категории `"normal"`, а `71` к категории `"wet"`.

Запишите выбор категории с помощью охранных условий. Используйте `otherwise` для завершающей ветви, чтобы функция возвращала результат для каждого допустимого показания.

Результат должен в точности совпадать с одной из указанных строк. Выводить его на экран не требуется.
