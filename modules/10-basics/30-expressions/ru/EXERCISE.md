Определите две строки и функцию для оформления коротких подписей.

- Имя `edge` должно обозначать строку `"|"`.
- Имя `gap` должно обозначать строку из одного пробела `" "`.
- Функция `makeBadge :: String -> String` должна принимать текст и возвращать его между двумя краями с пробелом с каждой стороны текста.

В определении `makeBadge` используйте имена `edge` и `gap` повторно. Соединяйте строковые части через `++`. Значения `edge` и `gap` должны быть отдельными определениями на уровне файла.

Например, применение функции к слову даёт такую подпись.

```haskell
makeBadge "Book"
```

Результат этого выражения равен `"| Book |"`.

Функция принимает любые строки, включая пустую. Она сохраняет все символы входного текста и добавляет только указанное оформление. В этих примерах повторные пробелы тоже входят в результат.

```haskell
makeBadge ""    -- "|  |"
makeBadge " A " -- "|  A  |"
```

В первом случае между краями находятся два пробела. Во втором пробелы входного текста сохраняются рядом с добавленным оформлением.

Функция возвращает строку. Печатать её на экран не требуется.
