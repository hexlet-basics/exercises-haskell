В этом уроке мы изучим сопоставление с образцом в Haskell. Разберём выбор определения по значению аргумента и извлечение частей кортежа или списка. Мы научимся записывать полные наборы образцов и использовать разбор внутри выражения `case`.

Иногда вычисление зависит от формы входных данных. Например, у непустого списка есть первый элемент и оставшийся список, а пустой список этих частей не содержит. Сопоставление с образцом позволяет описать нужную форму аргумента и дать имена её частям. Эти имена становятся доступны в выражении результата.

## Литералы и общий случай

Одну функцию можно определить несколькими строками для разных образцов аргумента. Литерал в образце соответствует конкретному значению. Обычное имя соответствует любому значению подходящего типа и связывается с ним. Если само значение не нужно, вместо имени записывают `_`.

Например, программа формирует подпись для количества свободных мест. Нулю нужна отдельная подпись, а всем остальным допустимым значениям общая.

```haskell
seatsLabel :: Integer -> String
seatsLabel 0 = "No seats"
seatsLabel _ = "Seats available"
```

В этой функции первый образец подходит только числу `0`. Второй образец подходит любому другому аргументу, который до него дошёл. Для `seatsLabel 0` результат равен `"No seats"`, для `seatsLabel 12` получается `"Seats available"`. В примере программа передаёт только неотрицательные количества.

Образцы проверяются сверху вниз, используется первое подошедшее определение. Если поставить строку с `_` первой, она подойдёт и для нуля. Тогда специальная строка с образцом `0` уже не будет выбрана. Общий случай располагают после случаев, которые нужно обработать отдельно.

Если аргументов несколько, каждый получает свой образец. Строка определения подходит, только когда подходят все образцы по своим позициям. Например, добавим название помещения к подписи о местах.

```haskell
roomLabel :: String -> Integer -> String
roomLabel room 0 = room ++ " has no seats"
roomLabel room _ = room ++ " has seats available"
```

В этом коде имя `room` связывается с первым аргументом в обеих строках. Образец `0` во второй позиции выделяет отсутствие мест, а `_` пропускает число в общем случае. Выражение `roomLabel "Maple" 0` даёт `"Maple has no seats"`.

## Извлечение частей кортежа

Образец кортежа повторяет его форму. Имена внутри скобок связываются с отдельными компонентами. Например, запись товара содержит код и цену, а функция должна вернуть только код.

```haskell
productCode :: (String, Integer) -> String
productCode (code, _) = code
```

В этом коде образец `(code, _)` подходит любой паре указанного типа. Первый компонент становится доступен под именем `code`. Второй компонент не нужен для результата, поэтому на его месте стоит `_`. Применение `productCode ("Pencil", 80)` даёт `"Pencil"`.

## Пустой и непустой список

Образец `[]` соответствует только пустому списку. Образец `x : xs` подходит непустому списку, связывает его первый элемент с именем `x`, а оставшийся список с именем `xs`. Эти имена можно выбрать по смыслу задачи. Если список содержит один элемент, оставшаяся часть будет равна `[]`.

Запись образца связана со способом построения списка. Схема показывает оба направления для одних и тех же данных.

```text
Построение
7 : [11, 17]  ---->  [7, 11, 17]

Разбор по образцу x : xs
[7, 11, 17]   ---->  первый элемент x равен 7
                     остаток xs равен [11, 17]
```

На этой схеме `:` сначала соединяет элемент и список, а при сопоставлении помогает выделить те же две части. Образец `x : xs` не задаёт точную длину списка. Он требует только наличия первого элемента.

Например, функция может убрать первое показание датчика и вернуть оставшиеся. Для пустого входа договоримся возвращать пустой список.

```haskell
dropFirst :: [Integer] -> [Integer]
dropFirst [] = []
dropFirst (_ : remaining) = remaining
```

В этом коде определение `dropFirst [] = []` обрабатывает пустой список. Определение `dropFirst (_ : remaining) = remaining` выделяет оставшуюся часть непустого списка, а первый элемент пропускает через `_`. Применение `dropFirst [7, 11, 17]` возвращает `[11, 17]`, а `dropFirst [7]` возвращает `[]`. Скобки вокруг образца с `:` показывают, что он описывает один аргумент функции.

## Разбор внутри выражения

Конструкция `case ... of` позволяет сопоставить значение с образцами внутри определения. После `case` стоит разбираемое значение, после `of` ветви с образцом и результатом, разделённые `->`. Ветви располагаются на одном уровне отступа и проверяются сверху вниз.

Например, функция определяет, пришло ли хотя бы одно показание.

```haskell
hasReadings :: [Integer] -> Bool
hasReadings readings =
  case readings of
    [] -> False
    _ : _ -> True
```

В этой функции `hasReadings []` даёт `False`, а `hasReadings [7]` даёт `True`. Два знака `_` независимо пропускают первый элемент и оставшийся список. Результаты обеих ветвей имеют тип `Bool`, поэтому такой же тип имеет всё выражение `case`.

Набор образцов должен покрывать все допустимые входы. Для списка достаточно обработать `[]` и непустой случай с `:`. Если оставить только пустой случай, применение к непустому списку завершится ошибкой при вычислении результата. Компилятор может предупредить о неполном сопоставлении, но наличие такого предупреждения само по себе не добавляет отсутствующую ветвь.
