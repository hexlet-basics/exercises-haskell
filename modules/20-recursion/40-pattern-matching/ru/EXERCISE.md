Реализуйте функцию `firstOrDefault :: Integer -> [Integer] -> Integer`. Она возвращает первый элемент списка, а для пустого списка возвращает явно переданное значение по умолчанию.

Первый аргумент `fallback` содержит значение по умолчанию. Второй аргумент `values` содержит список целых чисел. В списке от `0` до `100` элементов. Значение `fallback` и каждый элемент списка находятся в диапазоне от `-1000` до `1000` включительно.

Результат для непустого списка всегда равен его первому элементу, включая ноль и отрицательное число. Значение `fallback` используется только при пустом входе.

Примеры показывают оба случая.

| Применение | Результат |
| --- | --- |
| `firstOrDefault 42 []` | `42` |
| `firstOrDefault 42 [7, 11, 17]` | `7` |
| `firstOrDefault 42 [0, 11]` | `0` |
| `firstOrDefault 42 [-5]` | `-5` |

Используйте сопоставление с образцом, обработав пустой и непустой списки. Можно записать отдельные определения функции либо выражение `case`. Стандартные функции, которые извлекают элемент без обработки пустого случая, для этой задачи не нужны. Выводить результат на экран не требуется.
