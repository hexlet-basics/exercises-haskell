Реализуйте функцию `itemTotal :: String -> Integer -> Integer -> (String, Integer)`.

Функция получает код товара, цену одной единицы в копейках и количество единиц. Она должна вернуть пару, в которой первый компонент содержит исходный код товара, а второй общую стоимость.

Цена находится в диапазоне от `0` до `1000000` копеек включительно. Количество находится в диапазоне от `0` до `1000` включительно. Код может быть любой строкой, включая пустую. Его нужно сохранить без изменений.

Например, `itemTotal "A12" 250 3` должно вернуть `("A12", 750)`. Три единицы по 250 копеек дают общую стоимость 750 копеек.

Если количество равно нулю или товар имеет нулевую цену, стоимость в результате равна `0`. Код товара при этом сохраняется. Например, `itemTotal "B7" 1000 0` возвращает `("B7", 0)`.

Соберите результат как пару из двух компонентов в указанном порядке. Возвращать текстовое представление пары или выводить результат на экран не требуется.
