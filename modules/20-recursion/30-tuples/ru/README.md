В этом уроке мы изучим кортежи в Haskell. Разберём объединение значений разных типов и чтение компонентов пары через `fst` и `snd`. Мы научимся описывать тип кортежа и возвращать несколько связанных результатов из функции.

Иногда одному результату нужны несколько частей с разными назначениями. Например, описание помещения включает его название и число мест. Кортеж позволяет собрать такие части в одно значение. Позиция каждого компонента задаёт его роль, а тип кортежа фиксирует типы всех компонентов.

## Пара значений

Кортеж из двух компонентов называется парой. Значения записываются в круглых скобках и разделяются запятой. Например, название переговорной комнаты и её вместимость можно сохранить вместе.

```haskell
room :: (String, Integer)
room = ("Cedar", 6)
```

В этом коде `room` имеет тип `(String, Integer)`. Первый компонент содержит строку `"Cedar"`, второй целое число `6`. В записи типа круглые скобки и запятая повторяют структуру значения.

Таблица показывает назначение каждой позиции этой пары.

| Позиция | Содержимое | Тип |
| --- | --- | --- |
| Первая | Название `"Cedar"` | `String` |
| Вторая | Число мест `6` | `Integer` |

В этой таблице позиция связывает часть значения с её типом. Пара `(6, "Cedar")` имеет уже тип `(Integer, String)`. При передаче пары функции порядок компонентов должен соответствовать её сигнатуре.

Тип кортежа фиксирует и количество компонентов. Пары `(String, Integer)` и тройки `(String, Integer, Bool)` имеют разную структуру. Например, к описанию комнаты можно добавить признак наличия проектора.

```haskell
equippedRoom :: (String, Integer, Bool)
equippedRoom = ("Cedar", 6, True)
```

В этом коде третий компонент имеет тип `Bool`. Все значения типа `(String, Integer, Bool)` содержат ровно три компонента в указанном порядке. Значения внутри позиций могут меняться между разными комнатами, а сама структура остаётся заданной типом.

## Чтение компонентов пары

Функция `fst` возвращает первый компонент пары, а `snd` второй. Например, из готового описания помещения можно получить отдельно название и вместимость.

```haskell
roomName :: String
roomName = fst room

capacity :: Integer
capacity = snd room
```

В этом коде `roomName` равно `"Cedar"`, а `capacity` равно `6`. Функции получают одно значение `room`, в котором уже объединены обе части. По типу этой пары определяется и тип каждого полученного компонента.

`fst` и `snd` работают именно с парами. Они подходят, например, и к `(String, Integer)`, и к `(Bool, String)`. Применение к тройке вроде `equippedRoom` не согласуется с их типом. Более подробный разбор составных значений требует другого приёма, с которым познакомимся дальше по курсу.

## Кортеж как результат функции

В компонентах кортежа могут стоять вычисляемые выражения. Поэтому функция способна собрать результат из исходных и полученных значений. Например, добавление одного места в комнате можно представить новым описанием помещения.

```haskell
addSeat :: (String, Integer) -> (String, Integer)
addSeat info = (fst info, snd info + 1)
```

В этом коде `addSeat` принимает пару, что видно по типу слева от `->`. Справа от стрелки указан тип новой пары. Название берётся через `fst info`, а вместимость вычисляется прибавлением единицы к `snd info`.

Применение `addSeat room` даёт `("Cedar", 7)`. Исходное значение `room` сохраняет вместимость `6`. Функция возвращает новое составное значение, с которым могут работать другие вычисления.

Пара подходит для результата с заранее известными ролями компонентов. Для последовательности произвольного числа одинаковых по назначению значений используется список. Например, коды всех помещений образуют список строк, а название одного помещения с его вместимостью образует пару. Такое различие помогает выбрать представление данных по задаче.
