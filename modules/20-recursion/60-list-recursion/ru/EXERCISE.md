Реализуйте функцию `removeInvalid :: Integer -> [Integer] -> [Integer]`, которая удаляет все недопустимые показания датчика.

Первый аргумент `invalid` содержит недопустимое значение, второй аргумент `readings` содержит список показаний. Верните новый список без всех элементов, равных `invalid`. Порядок остальных элементов и все их повторения должны сохраниться.

Список содержит от `0` до `100` элементов. Аргумент `invalid` и каждое показание находятся в диапазоне от `-1000` до `1000` включительно. Пустому списку соответствует пустой результат. Если недопустимое значение не встретилось, результат должен содержать все исходные элементы. Если все показания недопустимы, верните `[]`.

Примеры показывают удаление одного и нескольких вхождений.

| Применение | Результат |
| --- | --- |
| `removeInvalid 99 [10, 99, 20, 99]` | `[10, 20]` |
| `removeInvalid 0 [0, 0, 0]` | `[]` |
| `removeInvalid 5 [1, 2, 1]` | `[1, 2, 1]` |
| `removeInvalid (-1) [-1, 10, -1, 20]` | `[10, 20]` |
| `removeInvalid 99 []` | `[]` |

Используйте рекурсивное определение с разбором пустого и непустого списка. В рекурсивный вызов передавайте оставшуюся часть списка, сохраняя значение `invalid`. Выводить результат на экран не требуется.
