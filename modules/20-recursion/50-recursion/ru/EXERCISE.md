Реализуйте функцию `sumFirst` с сигнатурой `Integer -> Integer`. Она принимает количество `n` и возвращает сумму первых `n` неотрицательных целых чисел.

Первым таким числом является `0`. Поэтому для `n`, равного `4`, складываются числа `0`, `1`, `2` и `3`. Последнее слагаемое равно `n - 1`. Для `n`, равного нулю, слагаемых нет и результат должен быть равен `0`.

Допустимый диапазон входа составляет от `0` до `1000` включительно. Отрицательные числа и значения больше `1000` обрабатывать не требуется.

Используйте рекурсию. Опишите готовый результат для базового случая и вычисление через меньшую задачу для остальных допустимых входов. Для такого определения достаточно числового аргумента, строить список не требуется.

Примеры показывают ожидаемые результаты.

```haskell
sumFirst 0  -- 0
sumFirst 1  -- 0
sumFirst 4  -- 6
sumFirst 10 -- 45
```

Функция возвращает одно целое число. Выводить результат на экран не требуется.
