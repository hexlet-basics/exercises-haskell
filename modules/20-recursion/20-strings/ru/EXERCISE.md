Реализуйте функцию `normalizeSpaces` с сигнатурой `String -> String`. Она принимает сообщение и возвращает текст, в котором соседние слова разделены одним обычным пробелом.

Начальные и конечные пробельные символы должны исчезнуть. Разделителями считаются все пробельные символы, включая обычный пробел, табуляцию, перевод строки и возврат каретки. Любую последовательность разделителей между словами замените одним обычным пробелом.

Сохраните сами слова без изменений. Регистр, цифры и знаки препинания внутри слов остаются такими, как во входной строке. Пустая строка и строка только из пробельных символов дают пустой результат.

Примеры показывают ожидаемые результаты. В литералах `\t` обозначает табуляцию, `\n` обозначает перевод строки, а `\r` обозначает возврат каретки.

| Применение | Результат |
| --- | --- |
| `normalizeSpaces "  Ready   to start  "` | `"Ready to start"` |
| `normalizeSpaces "Sensor\tA7\nready"` | `"Sensor A7 ready"` |
| `normalizeSpaces "Keep,  CASE!"` | `"Keep, CASE!"` |
| `normalizeSpaces " \t\n\r "` | `""` |

Никакой другой обработки текста делать не требуется.
