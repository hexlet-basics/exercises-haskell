В этом уроке мы изучим строки как списки символов в Haskell. Разберём получение частей текста и готовые функции разбиения по словам и строкам. Мы научимся выбирать представление текста для обработки и собирать строковый результат из его частей.

Текст можно обрабатывать целиком или разделять на меньшие части. Например, для краткой версии отчёта нужны первые строки, а для отдельного кода товара может понадобиться начало текста. Представление строки списком позволяет использовать уже известные операции над последовательностями.

## Символы и строки

Тип `Char` представляет отдельный символ Unicode. Его литерал записывается в одинарных кавычках, например `'A'`. Тип `String` является другим именем типа `[Char]`. Строка содержит упорядоченный список значений `Char`, в том числе пустой список.

Например, короткий код можно записать строковым литералом или перечислить его символы явно.

```haskell
shortCode :: String
shortCode = "A1"

sameCode :: [Char]
sameCode = ['A', '1']
```

В этом коде `shortCode` и `sameCode` имеют одинаковые значения и одинаковый тип. Записи `String` и `[Char]` взаимозаменяемы. У отдельного `'A'` тип `Char`, а у строки `"A"` тип `String`. К строке можно добавить один символ через `:`, например `'A' : "1"` даёт `"A1"`.

Функции для списков применяются и к строкам. В таблице показаны результаты применения этих функций к тексту и типы полученных значений.

| Выражение | Результат | Тип результата |
| --- | --- | --- |
| `length "A1-B2"` | `5` | `Int` |
| `take 2 "A1-B2"` | `"A1"` | `String` |
| `drop 3 "A1-B2"` | `"B2"` | `String` |

Количество для `take` и `drop` имеет тип `Int`. Эти операции сохраняют порядок символов. Для пустой строки `length` даёт ноль, а `take` и `drop` возвращают пустую строку.

Функция `length` считает элементы типа `Char`. Видимый знак иногда состоит из нескольких таких элементов. Поэтому измерение длины в `Char` и подсчёт видимых знаков могут дать разные результаты. Более сложная обработка отображаемого текста требует дополнительных правил и в этот урок не входит.

## Разбиение на строки

Функция `lines :: String -> [String]` разделяет текст по символам перевода строки. Элемент результата сам является строкой. Обозначение `[String]` читается как «список строк».

Пусть отчёт содержит названия трёх отделов, каждое на собственной строке. В литерале последовательность `\n` обозначает один символ перевода строки. Для текста `"North\nSouth\nWest\n"` применение `lines` даёт `["North", "South", "West"]`. Символы перевода строки в эти элементы не входят.

Функция `unlines :: [String] -> String` собирает строки вместе, добавляя после каждого элемента перевод строки. В том числе он появляется после последнего элемента. Например, `unlines ["North", "South"]` даёт `"North\nSouth\n"`. Для пустого списка результатом будет `""`.

Теперь краткий отчёт можно получить через известную `take`. Функция ниже сохраняет не более указанного количества первых строк.

```haskell
firstRows :: Int -> String -> String
firstRows count report = unlines (take count (lines report))
```

В этом коде `lines report` создаёт список строк, `take count` выбирает его начало, а `unlines` формирует текст. Для `firstRows 2 "North\nSouth\nWest\n"` получаем `"North\nSouth\n"`.

Схема показывает изменение представления данных в этом вычислении.

```text
report :: String
      |
    lines
      v
  [String]
      |
  take count
      v
  [String]
      |
   unlines
      v
    String
```

Здесь выбор выполняется над списком строк. Если исходный текст не оканчивался переводом строки, `unlines` всё равно добавит его после последнего выбранного элемента. Пустые строки внутри текста сохраняются как пустые элементы, например `lines "A\n\nB"` даёт `["A", "", "B"]`.

## Разбиение на слова

Функция `words :: String -> [String]` разделяет текст по пробельным символам. Разделителями служат пробельные символы, например обычный пробел, табуляция, перевод строки и возврат каретки. Несколько разделителей подряд не создают пустые слова. Например, `words "  red\tgreen  blue\n"` даёт `["red", "green", "blue"]`. Последовательность `\t` в литерале обозначает символ табуляции. Возврат каретки записывается как `\r` и тоже служит разделителем для `words`. В сочетании `\r\n` оба символа разделяют слова.

Здесь словом считается фрагмент между пробельными символами. Поэтому знак препинания остаётся частью фрагмента, а регистр букв сохраняется. Для пустого текста или текста только из разделителей `words` возвращает `[]`.

Функция `unwords :: [String] -> String` соединяет элементы одним обычным пробелом. Например, `unwords ["red", "green", "blue"]` возвращает `"red green blue"`. Соединитель добавляется между соседними элементами, а их содержимое сохраняется. Пустой список превращается в `""`.

После разбиения через `words` исходное количество разделителей уже не хранится в списке. Поэтому последующая сборка через `unwords` может изменить пробелы и переводы строк исходного текста. При выборе функции важно решить, какую структуру текста нужно сохранить.
