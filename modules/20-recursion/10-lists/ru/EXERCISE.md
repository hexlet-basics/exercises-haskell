Реализуйте функцию `combineReadings :: Int -> Int -> [Integer] -> [Integer] -> [Integer]`. Она собирает отчёт из показаний двух датчиков.

Аргументы идут в следующем порядке.

- `keepCount` задаёт, сколько первых показаний нужно оставить от первого датчика.
- `skipCount` задаёт, сколько первых показаний нужно пропустить у второго датчика.
- `primary` содержит показания первого датчика.
- `backup` содержит показания второго датчика.

Верните новый список, в котором сначала находится нужное начало `primary`, затем оставшаяся часть `backup`. Сохраняйте порядок элементов и повторяющиеся значения.

Оба количества имеют тип `Int` и находятся в диапазоне от `0` до `1000` включительно. Каждый входной список содержит не более `100` элементов типа `Integer`, каждое показание находится в диапазоне от `-1000` до `1000` включительно. Любой список может быть пустым.

Если `keepCount` больше длины первого списка, используйте его целиком. Если `skipCount` не меньше длины второго списка, его часть результата будет пустой. При нулевом `keepCount` первый список ничего не добавляет в результат. При нулевом `skipCount` второй список используется целиком.

Примеры показывают результат для обычных и коротких входов.

| Применение | Результат |
| --- | --- |
| `combineReadings 2 1 [10, 20, 30] [40, 50, 60]` | `[10, 20, 50, 60]` |
| `combineReadings 5 0 [10] [20, 30]` | `[10, 20, 30]` |
| `combineReadings 0 2 [10, 20] [30]` | `[]` |
| `combineReadings 2 0 [] [30, 40]` | `[30, 40]` |

Для решения достаточно `take`, `drop` и `++`. Выводить результат на экран не требуется.
