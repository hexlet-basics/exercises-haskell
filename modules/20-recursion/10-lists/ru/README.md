В этом уроке мы изучим списки в Haskell. Разберём построение списка, соединение последовательностей и получение их частей. Мы научимся записывать тип списка и выбирать функции для работы с его длиной и началом.

Когда функция обрабатывает несколько показаний датчика, их удобно передать как одно значение. Список хранит упорядоченную последовательность элементов. Число элементов может быть разным, включая ноль. Все элементы одного списка должны иметь одинаковый тип.

## Запись списка

Элементы перечисляются в квадратных скобках через запятую. Тип `[Integer]` обозначает список, каждый элемент которого имеет тип `Integer`. Например, программа может хранить три целых показания и отдельный список без показаний.

```haskell
readings :: [Integer]
readings = [12, 9, 15]

noReadings :: [Integer]
noReadings = []
```

В этом коде `readings` содержит три числа в заданном порядке. Значение `noReadings` является пустым списком. Его сигнатура указывает тип элементов, хотя самих элементов в нём нет. Пустой список подходит для результата вычисления, в котором пока нет данных.

## Построение из элемента и списка

Оператор `:` создаёт список, добавляя один элемент в начало другого списка. Слева от `:` стоит элемент, справа список с элементами того же типа. Так можно присоединить новое показание перед уже собранными значениями.

```haskell
updatedReadings :: [Integer]
updatedReadings = 8 : [12, 9, 15]
```

В этом коде результатом будет `[8, 12, 9, 15]`. Исходный список `[12, 9, 15]` сохраняется. Новое значение описывает последовательность с дополнительным первым элементом.

Пустой список завершает построение. Например, `8 : []` содержит один элемент, а `8 : 12 : []` содержит два. Схема раскрывает запись `[8, 12]` через её составные части. Запись `8 : 12 : []` читается как `8 : (12 : [])`, поскольку оператор `:` группирует построение справа.

```text
8 : (12 : [])
|     |    |
|     |    Пустой список завершает построение
|     Второй элемент
Первый элемент
```

На этой схеме `12 : []` образует список `[12]`. Присоединение `8` даёт `[8, 12]`. Запись `:` соединяет один элемент с оставшимся списком, поэтому справа от неё нужен список, в том числе пустой.

Для соединения двух списков используется `++`. Например, `[8, 12] ++ [9, 15]` даёт `[8, 12, 9, 15]`. Все элементы первого списка остаются перед элементами второго. Порядок и повторяющиеся значения сохраняются. Выражения `[] ++ [9, 15]` и `[9, 15] ++ []` дают `[9, 15]`.

## Конечный диапазон

Последовательные целые числа можно записать через границы диапазона. Например, программа формирует номера пяти соседних мест.

```haskell
seatNumbers :: [Integer]
seatNumbers = [21 .. 25]
```

В этом коде `seatNumbers` содержит `[21, 22, 23, 24, 25]`. Для такой записи целочисленного диапазона шаг равен единице, обе границы входят в результат. Если начало больше конца, например `[25 .. 21]`, получится пустой список. Здесь мы работаем с конечными диапазонами целых чисел.

## Длина и части списка

Функция `length` возвращает число элементов конечного списка. Функция `take` получает количество и список, затем возвращает не более указанного количества элементов с начала. Функция `drop` пропускает указанное количество элементов и возвращает оставшийся список.

Рассмотрим их применение к спискам целых чисел. В таблице приведены специализации для `[Integer]`; стандартные функции поддерживают и другие типы элементов.

| Функция | Тип для нашего случая | Пример результата |
| --- | --- | --- |
| `length` | `[Integer] -> Int` | `length [12, 9, 15]` даёт `3` |
| `take` | `Int -> [Integer] -> [Integer]` | `take 2 [12, 9, 15]` даёт `[12, 9]` |
| `drop` | `Int -> [Integer] -> [Integer]` | `drop 2 [12, 9, 15]` даёт `[15]` |

Здесь показания имеют тип `Integer`, а количество элементов имеет тип `Int`. Поэтому параметр количества для `take` и `drop` объявляется как `Int`, даже если сами элементы списка являются `Integer`. Результат `length` можно передать этим функциям непосредственно, поскольку его тип тоже `Int`.

Если запросить больше элементов, чем есть, `take` вернёт весь список, а `drop` пустой список. При количестве, равном нулю, `take` возвращает `[]`, а `drop` исходный список. Обе функции работают и с пустым входом, результатом будет `[]`. Все эти операции создают результат без изменения исходного значения.
