Реализуйте функцию `validateQuantity :: Integer -> Either String Integer`, которая проверяет количество товара.

Допустимым считается целое количество от `1` до `1000` включительно. Для допустимого количества верните `Right` с исходным значением без изменений.

Для недопустимого количества верните `Left` с точной причиной отказа.

| Количество | Причина внутри `Left` |
| --- | --- |
| Меньше `1` | `"Quantity must be at least 1"` |
| Больше `1000` | `"Quantity must be at most 1000"` |

Например, `validateQuantity 1` возвращает `Right 1`, а `validateQuantity 1000` возвращает `Right 1000`. Для `validateQuantity 0` результатом должен быть `Left "Quantity must be at least 1"`, а для `validateQuantity 1001` результатом должен быть `Left "Quantity must be at most 1000"`.

Функция принимает любое значение `Integer`, включая отрицательные числа. Отрицательное количество также относится к случаю «меньше 1». Возвращайте значение `Either`, выводить сообщения на экран не требуется.
