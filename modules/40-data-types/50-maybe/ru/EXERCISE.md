Реализуйте функцию `findFirst :: (a -> Bool) -> [a] -> Maybe a`, которая находит первый элемент списка, удовлетворяющий переданному условию.

Первый аргумент `predicate` является предикатом, функцией проверки одного элемента. Она возвращает `True` для подходящего значения и `False` для неподходящего. Второй аргумент `values` содержит конечный список, в котором от `0` до `100` элементов одного типа.

Если подходящий элемент есть, верните `Just` с исходным значением этого элемента. При нескольких совпадениях нужен первый элемент в порядке списка. Для пустого списка или отсутствия совпадений верните `Nothing`.

Функция должна подходить для любых типов элементов. Предикат передаётся готовым и определён для каждого входного элемента, поэтому сама `findFirst` не должна сравнивать элементы между собой или предполагать, что они являются числами.

Примеры показывают поиск чисел, строк и логических значений.

| Применение | Результат |
| --- | --- |
| `findFirst (\value -> value > 0) [-5, 3, 8]` | `Just 3` |
| `findFirst (\value -> value > 0) [-5, 0]` | `Nothing` |
| `findFirst (\value -> value == 0) [4, 0, 2]` | `Just 0` |
| `findFirst (\text -> length text >= 3) ["a", "cat", "horse"]` | `Just "cat"` |
| `findFirst (\value -> value) [False, True, True]` | `Just True` |

Используйте разбор списка и рекурсивное продолжение поиска, когда текущий элемент не подходит. Не подставляйте фиктивное значение вместо `Nothing`. Выводить результат на экран не требуется.
