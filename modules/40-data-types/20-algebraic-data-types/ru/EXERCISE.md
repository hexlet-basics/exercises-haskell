Объявите тип `Delivery`, который описывает способ получения заказа. Нужны три конструктора.

| Конструктор | Данные | Смысл |
| --- | --- | --- |
| `Pickup` | Без дополнительных данных | Самовывоз |
| `Courier` | Один `Integer` | Расстояние курьерской доставки в километрах |
| `Locker` | Один `String` | Код пункта выдачи |

Реализуйте функцию `handlingCost :: Delivery -> Integer`, возвращающую стоимость обработки заказа в целых рублях.

- Для `Pickup` стоимость равна `0`.
- Для `Courier distance` стоимость равна `150` рублям плюс `20` рублей за каждый километр.
- Для `Locker code` стоимость равна `100` рублям независимо от кода пункта выдачи.

Расстояние является целым числом от `0` до `1000` включительно. Код пункта выдачи является строкой длиной не более `40` символов, в том числе пустой. Проверять корректность кода в этой задаче не нужно.

Примеры показывают все варианты получения заказа.

| Применение | Результат |
| --- | --- |
| `handlingCost Pickup` | `0` |
| `handlingCost (Courier 0)` | `150` |
| `handlingCost (Courier 12)` | `390` |
| `handlingCost (Locker "L-7")` | `100` |

Используйте сопоставление с образцом и обработайте каждый конструктор. Добавьте объявление `Delivery`, затем указанную выше сигнатуру `handlingCost` и определения функции. Выводить собственные значения типа `Delivery` или результат функции на экран не требуется.
