В этом уроке мы изучим собственные типы с параметром. Разберём переменную типа в объявлении `data` и различие между созданием типа и созданием значения. Мы научимся описывать общую форму данных и писать функции для разных конкретных вариантов этой формы.

Иногда структура данных остаётся одинаковой, хотя тип её содержимого меняется. Например, парное измерение может хранить два целых показания или два логических состояния. Для общей формы можно ввести параметр типа. Он обозначает место, в котором при конкретном использовании будет выбран нужный тип.

## Параметр в объявлении data

Опишем тип `Duo`, который хранит два значения одного типа. Чтобы отделить названия типа и способа создания значения, конструктор значения назовём `MakeDuo`.

```haskell
data Duo a = MakeDuo a a
```

В этом объявлении `a` слева от `=` является параметром типа `Duo`. Справа от `=` тот же параметр задаёт тип каждого из двух полей `MakeDuo`. Имя параметра начинается со строчной буквы. Оба упоминания `a` обозначают один и тот же выбранный тип.

Теперь можно описать конкретные значения с общей формой и разным содержимым.

```haskell
counts :: Duo Integer
counts = MakeDuo 3 7

switches :: Duo Bool
switches = MakeDuo True False
```

В этом коде сигнатура `counts` выбирает `Integer` вместо `a`, поэтому оба поля содержат целые числа. Сигнатура `switches` выбирает `Bool` и требует два логических значения. Сами объявления данных повторять для каждого выбора не требуется.

Типы `Duo Integer` и `Duo Bool` различаются. Например, функция сложения двух целых показаний может явно принимать `Duo Integer`.

```haskell
sumDuo :: Duo Integer -> Integer
sumDuo (MakeDuo first second) = first + second
```

В этой функции образец `MakeDuo` выделяет оба числа, которые затем складываются. Выражение `sumDuo counts` даёт `10`. Значение `switches` содержит логические состояния, поэтому следующий вызов намеренно нарушает ожидаемый тип аргумента.

<!-- lint-code-blocks: skip — сознательно неверный вызов с Duo Bool вместо Duo Integer -->
```text
sumDuo switches
```

При проверке вызова GHC 9.0.2 сообщает о несовместимости. Ключевая часть фактической диагностики выглядит так.

```text
Couldn't match type ‘Bool’ with ‘Integer’
Expected: Duo Integer
  Actual: Duo Bool
In the first argument of ‘sumDuo’, namely ‘switches’
```

Здесь `Expected` показывает ожидаемый тип аргумента `Duo Integer`, а `Actual` показывает тип переданного значения `Duo Bool`. Общая форма `Duo` совпадает, но параметры `Integer` и `Bool` различаются. Компилятор отклоняет вызов до вычисления суммы.

## Конструктор типа и конструктор значения

Имя `Duo` обозначает конструктор типа. Вместе с типом параметра он образует конкретный тип, например `Duo String`. Имя `MakeDuo` обозначает конструктор значения. Он получает содержимое полей и создаёт значение выбранного типа.

Таблица сопоставляет эти роли в знакомом примере.

| Запись | Роль |
| --- | --- |
| `Duo` | Конструктор типа, которому нужен параметр типа |
| `Duo Integer` | Конкретный тип значения |
| `MakeDuo` | Конструктор значения с двумя полями |
| `MakeDuo 3 7` | Значение, которому контекст может задать тип `Duo Integer` |

Тип конструктора значения записывается как `a -> a -> Duo a`. Такая сигнатура связывает тип обоих аргументов с параметром результата. Для `MakeDuo True False` тип содержимого определяется как `Bool`. Для чисел в примере конкретный выбор `Integer` закреплён сигнатурой `counts`.

У конструктора типа и конструктора значения могут быть одинаковые имена, например в объявлении `data Box a = Box a`. Слева от `=` имя `Box` относится к типу, справа к способу построения значения. Различить их помогает место использования. В сигнатурах описываются типы, в выражениях и образцах используются конструкторы значений.

## Обобщённая функция

Параметр типа можно сохранить в сигнатуре функции. Тогда одна реализация будет работать с разными вариантами нашего типа данных. Функция сможет применять только те действия, для которых ей достаточно известной структуры.

Например, поменяем местами два измерения внутри `Duo`.

```haskell
swapDuo :: Duo a -> Duo a
swapDuo (MakeDuo first second) = MakeDuo second first
```

В этой функции образец выделяет оба поля. Справа конструктор создаёт новое значение с обратным расположением полей. Для `swapDuo counts` результат можно описать выражением `MakeDuo 7 3`, для `swapDuo switches` выражением `MakeDuo False True`. В каждом случае тип содержимого сохраняется.

Здесь нет операций над самими `first` и `second`, требующих знания их конкретного типа. Функция использует структуру `Duo` и переносит полученные значения в результат. Поэтому ей подходит и `Duo Integer`, и `Duo Bool`, и другая конкретная подстановка параметра.

В одном значении `Duo a` оба поля должны соответствовать выбранному `a`. Например, одновременно хранить число и логическое значение в полях такого `Duo` нельзя. Если предметная область требует разных типов полей, их можно описать отдельно. В упражнении одно поле будет иметь фиксированный тип `String`, а тип другого будет задаваться параметром.
