Объявите тип `Tagged a` с единственным конструктором `Tagged`. Он должен содержать два поля в следующем порядке.

- Текстовая метка типа `String`.
- Содержимое типа `a`.

Например, значение `Tagged "count" 12` хранит метку `"count"` и число. Значение `Tagged "ready" True` хранит метку и логическое содержимое. Тип содержимого выбирается независимо от текста метки.

Реализуйте функцию `tagValue` с сигнатурой `Tagged a -> a`. Она должна извлекать содержимое, сохраняя его значение и тип. Метку в результат включать не нужно. Используйте сопоставление с конструктором.

Примеры показывают ожидаемые результаты.

```haskell
tagValue (Tagged "count" 12)       -- 12
tagValue (Tagged "ready" True)     -- True
tagValue (Tagged "message" "Hi")   -- "Hi"
tagValue (Tagged "empty" "")       -- ""
```

Метка может быть пустой строкой. Содержимым может быть значение любого типа, включая список, пару или функцию. Дополнительные ограничения на тип `a` не нужны.
