В этом уроке мы изучим модули и импорт стандартной библиотеки Haskell. Разберём доступность имён, выборочный импорт и запись `qualified`. Мы научимся находить готовую функцию в документации и подключать её для обработки текста.

Библиотечные определения объединяются в модули по назначению. Например, операции с символами находятся в `Data.Char`. Импорт делает выбранные определения доступными в другом модуле. Благодаря этому можно использовать готовое правило обработки вместе с собственными функциями.

## Свой модуль и Prelude

Учебный файл _Solution.hs_ начинается строкой `module Solution where`. Она объявляет модуль с именем `Solution`. После неё располагаются импорты, затем определения этого модуля. Имя модуля пишется с заглавной буквы, имя обычной функции со строчной.

Известные `map`, `filter`, `length` и многие другие базовые функции доступны без явно написанного импорта. Их предоставляет модуль `Prelude`, который в обычной программе подключается автоматически. Поэтому для применения `map` в наших упражнениях дополнительная строка импорта не нужна.

В стандартной библиотеке есть и другие модули. Когда нужное имя отсутствует среди доступных определений, по документации можно установить его модуль и явно подключить это имя.

## Импорт выбранных имён

Пусть из сообщения о заказе нужно получить строку всех десятичных цифр. Например, из `"Order A-42/B7"` должен получиться текст `"427"`. Для отбора подходит известная `filter`, а правило проверки отдельного символа предоставляет `Data.Char`.

Функция `isDigit :: Char -> Bool` проверяет, является ли символ одной из цифр от `'0'` до `'9'`. Подключим только это имя.

```haskell
module Solution where

import Data.Char (isDigit)

digitsOnly :: String -> String
digitsOnly text = filter isDigit text
```

В этом коде строка `import Data.Char (isDigit)` делает функцию `isDigit` доступной по короткому имени. В скобках перечислены выбранные определения. Импорт располагается перед определением `digitsOnly`. Теперь `filter` получает подходящий предикат для элементов типа `Char`.

Для `digitsOnly "Order A-42/B7"` результатом будет `"427"`. Функция `digitsOnly` остаётся нашим определением, а `isDigit` взята из стандартной библиотеки. Схема показывает, откуда приходят используемые имена.

```text
Data.Char ── isDigit ──> Solution
Prelude   ── filter  ──> Solution
```

На этой схеме `isDigit` подключена явно, а `filter` доступна благодаря автоматическому импорту `Prelude`. Выборочный импорт помогает увидеть, какие возможности другого модуля нужны данному файлу. Запись без списка имён, например `import Data.Char`, делает доступными все определения, которые этот модуль предоставляет наружу.

## Квалифицированные имена

Если в программе появляются одинаковые короткие имена из разных источников, перед именем можно явно указывать модуль. Для этого используется импорт с `qualified`. Тот же пример можно записать с полным именем функции проверки.

```haskell
module Solution where

import qualified Data.Char

digitsOnly :: String -> String
digitsOnly text = filter Data.Char.isDigit text
```

В этой версии используется имя `Data.Char.isDigit`. Его префикс указывает модуль, предоставляющий функцию. После такого импорта короткое имя `isDigit` без префикса модуля недоступно. Полное имя помогает определить источник функции непосредственно в выражении.

У импорта можно дополнительно указать короткое имя через `as`, например `import qualified Data.Char as Char`. Тогда обращение записывается как `Char.isDigit`. Это имя для модуля в данном файле, а сама функция и её поведение сохраняются. Для небольшого учебного примера подходят оба варианта квалифицированного импорта.

## Чтение документации

В [официальной справке по операциям с символами](https://hackage.haskell.org/package/base/docs/Data-Char.html) рядом с именем функции находятся сигнатура и описание. Эти сведения помогают проверить, подходит ли операция для задачи.

Например, у `isSpace :: Char -> Bool` аргумент имеет тип `Char`, а результат имеет тип `Bool`. По этим типам видно, что функция служит предикатом для одного символа. Описание уточняет, что она проверяет, является ли символ пробельным. Поэтому `Data.Char.isSpace '\t'` даёт `True`, а `Data.Char.isSpace 'A'` даёт `False` при квалифицированном импорте `Data.Char`.

Тип помогает выбрать способ применения, а описание уточняет поведение. В частности, из одной сигнатуры `Char -> Bool` нельзя узнать, какие символы функция распознаёт. Для этого нужна справка рядом с именем. В упражнениях мы используем уже доступную стандартную библиотеку, поэтому достаточно добавить нужный импорт в тот же учебный файл.
