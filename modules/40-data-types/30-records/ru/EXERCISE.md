В каркасе определён тип `Product` с одним конструктором `Product` и двумя полями.

- `productCode` содержит код товара типа `String`.
- `productPrice` содержит цену товара в копейках типа `Integer`.

Для чтения значений этих полей доступны функции `productCode :: Product -> String` и `productPrice :: Product -> Integer`.

Реализуйте функцию `setPrice :: Product -> Integer -> Product`. Она принимает исходный товар и новую цену, а возвращает новое значение товара с этой ценой. Код должен сохраниться без изменений.

Исходная и новая цены находятся в диапазоне от `0` до `1000000` копеек включительно. Код может быть любой строкой, включая пустую. Проверять допустимость этих данных внутри функции не требуется.

Используйте обновление записи по имени поля. Например, если исходный товар имеет код `"A12"` и цену `1000`, после `setPrice` с новой ценой `1200` у результата должны быть тот же код `"A12"` и цена `1200`.

Исходный товар должен сохранить цену `1000`. Одно исходное значение можно использовать для получения нескольких товаров с разными ценами. Функция возвращает запись, выводить её на экран не требуется.
