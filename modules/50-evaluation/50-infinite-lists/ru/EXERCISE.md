Реализуйте функцию `scaledProgression :: Int -> Integer -> Integer -> [Integer]`. Она возвращает удвоенные значения первых членов арифметической последовательности.

Аргументы идут в следующем порядке.

- `count` задаёт количество нужных элементов, от `0` до `100` включительно.
- `start` задаёт первый член исходной последовательности.
- `step` задаёт разность соседних членов исходной последовательности.

Аргументы `start` и `step` имеют тип `Integer` и находятся в диапазоне от `-1000` до `1000` включительно. Исходная последовательность начинается со `start`, каждое следующее значение получается прибавлением `step` к предыдущему. Верните первые `count` значений этой последовательности, умножив каждое из них на `2`.

При нулевом `count` верните `[]`. Нулевой `step` означает повторение одного исходного значения. Отрицательный `step` означает уменьшение значений на каждом переходе. В результате должно быть ровно `count` элементов в исходном порядке.

Примеры показывают начало последовательности и её преобразование.

| Применение | Результат |
| --- | --- |
| `scaledProgression 4 3 2` | `[6, 10, 14, 18]` |
| `scaledProgression 3 5 0` | `[10, 10, 10]` |
| `scaledProgression 4 5 (-2)` | `[10, 6, 2, -2]` |
| `scaledProgression 1 (-3) 8` | `[-6]` |
| `scaledProgression 0 3 2` | `[]` |

Постройте источник через `iterate`, преобразуйте элементы через `map` и ограничьте результат через `take`. Правило следующего значения должно сохранять исходный `step`. Выводить список на экран не требуется.
