Реализуйте функцию `countLeaves :: Tree -> Integer`, которая считает конечные элементы в дереве упаковки.

Готовый тип `Tree` имеет два конструктора.

- `Item label` описывает один конечный элемент с числовой меткой `label :: Integer`.
- `Bundle left right` объединяет две части типа `Tree` и сам конечным элементом не является.

Каждое вхождение `Item` добавляет к результату ровно `1` независимо от метки. Для `Bundle` нужно учесть все конечные элементы обеих частей. Одинаковые метки в разных местах считаются отдельными элементами.

Входное дерево конечное и содержит от `1` до `100` вхождений конструктора `Item`. Метки находятся в диапазоне от `-1000` до `1000` включительно. Пустого варианта в этом типе нет. Считать значения меток или количество всех узлов не требуется.

Примеры показывают отличие элементов от объединений.

| Применение | Результат |
| --- | --- |
| `countLeaves (Item 500)` | `1` |
| `countLeaves (Item 0)` | `1` |
| `countLeaves (Bundle (Item 10) (Item 20))` | `2` |
| `countLeaves (Bundle (Item 10) (Bundle (Item 20) (Item 30)))` | `3` |
| `countLeaves (Bundle (Item 7) (Item 7))` | `2` |

Используйте сопоставление с образцом и рекурсивную обработку дочерних частей. Объявление `Tree` и сигнатура `countLeaves` уже даны в редакторе. Выводить результат на экран не требуется.
