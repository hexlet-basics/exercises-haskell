В этом уроке мы изучим создание собственного класса типов в Haskell. Разберём объявление общей операции и её реализации для двух конкретных типов. Мы научимся писать экземпляры класса и использовать их через функцию с ограничением типа.

В программе коробки и ящики уже описаны самостоятельными типами `Box` и `Crate`. С `Box` работают функции маркировки коробок, с `Crate` функции размещения ящиков на складе. Для обоих типов нужна общая проверка, помещается ли содержимое в свободную часть хранилища. Замена этих типов одним типом с двумя вариантами потребовала бы изменить объявления существующих функций и места их вызова.

Для такой проверки достаточно общей операции получения количества предметов. Коробка может хранить количество прямо в значении, а ящик вычислять его из числа рядов и предметов в ряду. Класс типов задаёт общую операцию, а экземпляр класса определяет её реализацию для конкретного типа. Существующие функции продолжают работать со своими типами.

## Объявление операции

Рассмотрим два учебных типа упаковки. В коробке сразу указано число предметов. В ящике указаны количество рядов и число предметов в одном ряду.

```haskell
data Box = Box Integer
data Crate = Crate Integer Integer
```

В этом коде `Box` хранит одно целое число, а `Crate` два. Например, `Box 8` представляет коробку с восемью предметами. Значение `Crate 3 4` представляет три ряда по четыре предмета. Для обоих типов полезна операция получения общего количества.

Такую операцию можно объявить в собственном классе типов.

```haskell
class HasCount a where
  itemCount :: a -> Integer
```

В этом коде `HasCount` является именем класса, а `a` параметром типа. Операция `itemCount` принимает значение этого типа и возвращает `Integer`. Объявление описывает требуемую операцию, а конкретные правила вычисления задаются экземплярами класса.

Операция класса также называется методом. При её использовании учитывается ограничение класса, поэтому полный тип `itemCount` читается как `HasCount a => a -> Integer`. Чтобы вызвать её для конкретного типа, этому типу нужна реализация `HasCount`.

## Экземпляры класса

Для коробки количество уже находится внутри конструктора. В экземпляре класса достаточно извлечь это поле.

```haskell
instance HasCount Box where
  itemCount (Box count) = count
```

В этом коде `instance HasCount Box` задаёт реализацию `HasCount` для типа `Box`. Образец `Box count` извлекает число. Применение `itemCount (Box 8)` даёт `8`. Сигнатуру метода уже задаёт класс, а внутри экземпляра записывается его определение.

Для ящика правило вычисления другое, поэтому объявляется второй экземпляр.

```haskell
instance HasCount Crate where
  itemCount (Crate rows perRow) = rows * perRow
```

В этом коде `itemCount` получает два поля из значения `Crate` и перемножает их. Для `itemCount (Crate 3 4)` результат равен `12`. Имя операции осталось общим, а её реализация соответствует структуре конкретного типа.

Таблица показывает связь между типом аргумента и выбранным правилом.

| Тип аргумента | Экземпляр | Правило получения количества |
| --- | --- | --- |
| `Box` | `HasCount Box` | Взять сохранённое количество |
| `Crate` | `HasCount Crate` | Умножить число рядов на количество в ряду |

В этой таблице выбор правила зависит от типа аргумента. Например, две разные коробки используют один экземпляр `HasCount Box`, хотя содержат разные количества. У ящиков применяется экземпляр `HasCount Crate`.

## Общая функция с ограничением

Объявленный класс можно использовать в сигнатуре другой функции. Например, система проверяет, помещается ли содержимое упаковки в свободную часть хранилища. Для решения достаточно узнать общее число предметов.

```haskell
canFit :: HasCount a => Integer -> a -> Bool
canFit capacity package = itemCount package <= capacity
```

В этом коде `capacity` задаёт свободное количество мест. Аргумент `package` имеет произвольный тип `a`, для которого доступен экземпляр `HasCount`. Ограничение позволяет вызвать `itemCount package` и сравнить полученное число с вместимостью.

Применение `canFit 10 (Box 8)` даёт `True`, а `canFit 10 (Crate 3 4)` даёт `False`. Одна функция работает с обоими типами упаковки. При проверке конкретного вызова компилятор согласует тип аргумента с ограничением и подбирает соответствующий экземпляр.

Новый тип сможет участвовать в таком вычислении после определения своей реализации `HasCount`. Тело `canFit` при этом продолжит пользоваться той же операцией. Смысл класса задаётся общим требованием, что `itemCount` возвращает количество предметов, независимо от способа хранения этих данных.
