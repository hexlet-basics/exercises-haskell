В каркасе определены два типа данных.

- `Book` с конструктором `Book` хранит название книги типа `String` и число страниц типа `Integer`.
- `Course` с конструктором `Course` хранит название курса типа `String` и число уроков типа `Integer`.

Объявите класс типов `ShortLabel a` с одним методом `shortLabel :: a -> String`. Затем определите экземпляры `ShortLabel` для типов `Book` и `Course`.

Метод должен возвращать краткую подпись в точном формате для соответствующего типа.

| Значение | Результат |
| --- | --- |
| `Book "FP" 120` | `"Book: FP \| pages=120"` |
| `Course "Photography" 12` | `"Course: Photography \| lessons=12"` |

Для книги подпись начинается со строки `"Book: "`, затем содержит исходное название, строку `" | pages="` и число страниц. Для курса используется начало `"Course: "` и разделитель `" | lessons="` перед числом уроков.

Название может быть любой строкой, включая пустую. Сохраняйте его без изменений. Число страниц или уроков находится в диапазоне от `0` до `1000000` включительно. Для получения строкового представления числа используйте `show`.

Оба экземпляра должны использовать один метод `shortLabel`. Изменять объявления `Book` и `Course` или добавлять к ним другие экземпляры классов не требуется. Метод возвращает строку, выводить её на экран не нужно.
