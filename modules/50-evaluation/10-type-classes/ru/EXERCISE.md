Запишите обобщённую сигнатуру и реализуйте функцию `findPosition`. Она находит позицию первого вхождения заданного значения в списке. Выберите достаточное ограничение класса типов для сравнения на равенство.

Первый аргумент `target` содержит искомое значение произвольного типа, второй аргумент `values` содержит конечный список элементов того же типа. В списке от `0` до `100` элементов. Результат функции имеет тип `Maybe Integer`.

Позиции начинаются с `0`. Для найденного элемента верните `Just` с его позицией типа `Integer`. Если совпадений несколько, нужна самая маленькая позиция. Для пустого списка и отсутствующего значения верните `Nothing`.

Примеры показывают поиск значений разных типов.

| Применение | Результат |
| --- | --- |
| `findPosition 7 [7, 2, 7]` | `Just 0` |
| `findPosition 7 [2, 7, 7]` | `Just 1` |
| `findPosition 9 [2, 7]` | `Nothing` |
| `findPosition "B" ["A", "B", "C"]` | `Just 1` |
| `findPosition True [False, False, True]` | `Just 2` |

Элементам достаточно поддерживать сравнение на равенство. Функция должна подходить и для типов без упорядочивания и текстового представления. При продолжении поиска в оставшейся части списка учтите, что её позиции сдвинуты на один относительно исходного списка. Выводить результат на экран не нужно.
