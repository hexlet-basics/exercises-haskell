Реализуйте функцию `preview` с сигнатурой `Bool -> Int -> [Integer] -> [Integer]`. Она получает признак включённого предварительного просмотра, запрошенное количество элементов и последовательность показаний.

Если первый аргумент равен `False`, верните пустой список. В этом случае сама последовательность не нужна для результата.

Если первый аргумент равен `True`, верните не более указанного количества элементов с начала последовательности. Сохраните их значения, порядок и повторения. Для нулевого количества результатом будет пустой список. В этом случае сама последовательность тоже не нужна для результата. Если обычная конечная последовательность короче запроса, верните её целиком.

Для обычных входов количество находится в диапазоне от `0` до `1000` включительно. Показания являются целыми числами. Во время проверки части последовательности могут быть подготовлены как ошибочные вычисления, чтобы проверить, потребовало ли решение лишние данные.

Решению должны быть нужны только запрошенная часть структуры списка и те значения, которые затем использует вызывающий код. Ошибочный хвост после выбранных элементов не должен влиять на результат. При подсчёте длины полученного префикса значения его элементов тоже не нужны.

Обычные примеры показывают ожидаемые результаты.

```haskell
preview True 2 [12, 7, 18]  -- [12, 7]
preview False 2 [12, 7, 18] -- []
preview True 5 [12, 7]      -- [12, 7]
preview True 0 [12, 7]      -- []
```

Используйте изученные `if` и `take`. Не вычисляйте длину всего входа перед получением начала списка. Добавлять ошибочные выражения в решение не требуется.
