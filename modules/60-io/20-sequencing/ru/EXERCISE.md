Допишите действие `main :: IO ()`, которое печатает готовые строки короткого отчёта в заданном порядке. В редакторе уже даны определения `reportTitle :: String`, `reportSummary :: String` и `reportStatus :: String`. Используйте эти значения для вывода. Между названием отчёта и его содержимым должна находиться одна пустая строка.

Ожидается ровно такой вывод.

```text
Weekly report

Completed: 3
Status: ready
```

Сначала выведите `reportTitle`, затем пустую строку, затем `reportSummary` и `reportStatus`. После каждой из четырёх строк, включая последнюю, нужен перевод строки. Дополнительных строк и пробелов не требуется. Действие `putStrLn ""` подходит для пустой строки.

Строка `main = do` уже дана в каркасе. Внутри блока добавьте действия `putStrLn` с одинаковым отступом в два пробела. Готовые строковые определения изменять не нужно. Входных данных у программы нет.
