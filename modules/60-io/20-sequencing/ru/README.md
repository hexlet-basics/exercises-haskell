В этом уроке мы изучим последовательность действий `IO` в Haskell. Разберём запись блока `do`, значимые отступы и роль последнего действия. Мы научимся составлять программу из нескольких действий вывода и задавать порядок её сообщений.

Отдельное действие вывода описывает одну операцию с внешним миром. Программе часто нужно выполнить несколько таких операций в определённом порядке. Например, сначала показать название отчёта, затем его содержимое. Блок `do` соединяет действия в одну последовательность.

## Несколько действий в одном блоке

После `do` действия можно записать на отдельных строках. При исполнении полученного действия они выполняются в указанном порядке. Например, программа печатает название устройства, его состояние и количество готовых каналов.

```haskell
deviceTitle :: String
deviceTitle = "Device " ++ "A7"

readyChannels :: Integer
readyChannels = 3

main :: IO ()
main = do
  putStrLn deviceTitle
  putStrLn "Connection ready"
  print readyChannels
```

В этой программе первое действие выводит значение `deviceTitle`, второе выводит строку состояния, третье выводит число через `print`. При запуске получаем такой текст.

```text
Device A7
Connection ready
3
```

Схема связывает строки блока `do` с сообщениями в консоли и показывает тип составного действия.

```text
Блок do                                    Консоль
main = do
  putStrLn deviceTitle ------------------> Device A7
  putStrLn "Connection ready" -----------> Connection ready
  print readyChannels -------------------> 3
         |
         +-- тип последнего действия IO ()
                        |
                        v
                 тип всего блока IO ()
                 результат исполнения ()
```

На этой схеме горизонтальные стрелки связывают каждое действие с его строкой вывода. Действия исполняются сверху вниз. Последний `print` имеет тип `IO ()`, поэтому весь блок тоже имеет тип `IO ()` и при исполнении возвращает `()`. Это значение не добавляет строку в консоль. Если поменять местами строки с `putStrLn` и `print`, изменится порядок сообщений. Наличие имени `deviceTitle` само по себе ничего не выводит, оно только предоставляет строковое значение действию.

## Отступы и пустые строки

Строки одного блока `do` располагаются на одинаковом уровне отступа. В примере действия сдвинуты на два пробела относительно определения `main`. Такой отступ показывает, что все три строки принадлежат одному блоку.

Перенос строки в исходном файле отделяет записи действий. Каждый вызов `putStrLn` дополнительно выводит перевод строки в результат программы. Поэтому для пустой строки в отчёте можно использовать действие `putStrLn ""`, которое выводит один перевод строки.

Пустая строка между определениями в самом файле не создаёт пустую строку вывода. Для нужного промежутка в выводе программа должна содержать соответствующее действие. Так мы отдельно задаём оформление кода и оформление сообщений.

## Последнее действие и результат

Блок `do` сам является выражением, описывающим составное действие. Значение, возвращаемое последним действием, становится результатом всего блока. В наших примерах последним стоит действие вывода типа `IO ()`. Поэтому весь блок тоже имеет тип `IO ()`, а его результатом после исполнения является `()`.

Каждая строка последовательности здесь описывает действие. Обычная строка текста не заменяет действие вывода. Например, такое определение содержит ошибку типов.

<!-- lint-code-blocks: skip — намеренно записано чистое строковое значение вместо последнего действия do -->
```text
wrong :: IO ()
wrong = do
  putStrLn "Started"
  "Finished"
```

GHC отклоняет это определение при проверке типов. Ключевая часть сообщения показывает ожидаемый и фактический типы последнего выражения.

```text
    • Couldn't match type ‘[]’ with ‘IO’
      Expected: IO ()
        Actual: String
    • In a stmt of a 'do' block: "Finished"
```

В строке `Expected` требуется действие `IO ()`, а `Actual` указывает на обычное строковое значение `String`. Обозначение `[]` в первой строке связано с тем, что `String` совпадает со списком символов `[Char]`. Указание `In a stmt of a 'do' block` помогает найти проблемную строку `"Finished"`. Для вывода этого текста подходит действие `putStrLn "Finished"`, имеющее нужный тип `IO ()`.

## Порядок действий и чистые вычисления

`do` задаёт порядок взаимодействий с внешним миром. Выражение `"Device " ++ "A7"` при этом остаётся чистым вычислением строки. Его определение не добавляет к последовательности новую операцию вывода.

Гарантированный порядок сообщений не требует считать, что все чистые выражения в программе вычисляются построчно. Их значения вычисляются по требованию с учётом зависимостей данных. Важно, что к моменту использования строкового результата действие получает нужный текст, а сами действия выполняются в порядке, записанном в блоке.
