Реализуйте чистую функцию `formatReading` с сигнатурой `Integer -> String`. Она получает целое показание и возвращает сообщение в формате `Reading: <число>`.

Используйте `show` для строкового представления числа. После двоеточия должен быть ровно один пробел. В самом результате `formatReading` перевода строки нет. Допустимо любое целое значение, в том числе ноль и отрицательное число.

Примеры показывают результаты чистой функции.

```haskell
formatReading 27   -- "Reading: 27"
formatReading 0    -- "Reading: 0"
formatReading (-7) -- "Reading: -7"
```

В каркасе уже определена константа `sampleReading` со значением `27`. Сохраните это определение. Добавьте действие `main` с сигнатурой `IO ()`, которое выводит результат `formatReading sampleReading` через `putStrLn`.

При выполнении `main` должна появиться одна строка.

```text
Reading: 27
```

После сообщения должен быть один перевод строки. Дополнительных кавычек, подписей и пустых строк в выводе быть не должно. Чтение ввода для этой задачи не требуется.
