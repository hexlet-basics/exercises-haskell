В этом уроке мы изучим действия IO для вывода данных. Разберём различие между вычисленной строкой и действием её вывода на экран. Мы научимся строить сообщение чистой функцией и описывать вывод этого сообщения через `main`.

Программа может вычислить правильный текст, но для передачи его человеку требуется взаимодействие с внешним миром. Вывод в консоль является таким взаимодействием. Haskell позволяет отдельно описать значение сообщения и действие, которое затем выведет его при выполнении программы.

Значение типа `String` содержит текст. Значение типа `IO ()` описывает действие, после выполнения которого результатом будет `()`. Обозначение `()` называется единичным типом и имеет единственное значение с такой же записью. При выводе сообщения этот результат обозначает отсутствие полезных возвращаемых данных, само же сообщение появляется в консоли.

## Сначала сообщение

Пусть программа сообщает о готовности устройства. Для выбора текста достаточно логического аргумента. Вычисление самого сообщения можно описать чистой функцией.

```haskell
statusMessage :: Bool -> String
statusMessage ready =
  if ready then "Device ready" else "Device idle"
```

В этой функции `statusMessage True` даёт строку `"Device ready"`. Для `False` результатом будет `"Device idle"`. Функция формирует значение текста и сама не выводит его на экран. Эту строку можно использовать и в другом чистом вычислении.

## Действие вывода

Функция `putStrLn` имеет тип `String -> IO ()`. Она получает строку и строит действие, которое выведет её с переводом строки в конце. Тип результата позволяет отличить это действие от текста, переданного аргументом.

Например, дадим действию имя `announcement`.

```haskell
announcement :: IO ()
announcement = putStrLn (statusMessage True)
```

В этом определении `announcement` обозначает действие вывода сообщения о готовности. Наличие такого определения в файле само по себе не означает выполнение действия. Оно задаёт значение, которое можно использовать как часть программы.

Начальное действие запускаемой программы обозначается именем `main`. В данном случае оно может быть тем же значением, что и `announcement`.

```haskell
main :: IO ()
main = announcement
```

Здесь `main` обозначает подготовленное действие. При его выполнении программа выводит одну строку `Device ready` и перевод строки после неё. Применение `putStrLn` описало нужное действие, а запуск программы приводит к его выполнению.

Схема показывает границу между значением сообщения и внешним результатом.

```text
True -- statusMessage --> String -- putStrLn --> IO ()
                                                  |
                                   выполнение действия main
                                                  v
                                      сообщение в консоли
```

На этой схеме чистая часть вычисляет текст. Следующий шаг строит действие вывода, которое получает имя `main`. Внешний результат появляется при выполнении действия. Разделение позволяет проверять формирование сообщения независимо от консольного вывода.

## Вывод через print

Для значения, тип которого поддерживает `Show`, доступна функция `print`. Её сигнатура имеет вид `Show a => a -> IO ()`. Она использует строковое представление через `show` и дополняет вывод переводом строки.

Для числа это удобно, когда требуется показать именно его представление. Для готового текстового сообщения обычно подходит `putStrLn`. Таблица показывает строки, которые появятся в консоли при выполнении действий.

| Выражение действия | Строка в консоли |
| --- | --- |
| `putStrLn "Ready"` | `Ready` |
| `print "Ready"` | `"Ready"` |
| `print (27 :: Integer)` | `27` |

В строке таблицы с `print "Ready"` кавычки являются частью результата `show` для значения типа `String`. Они действительно попадут в вывод. В строке с `putStrLn "Ready"` действие использует само содержимое переданного текста. Каждое действие в таблице добавляет перевод строки в конце.

## Строка и действие

Соединение строк через `++` требует строковых значений. Если попытаться присоединить к строке уже подготовленное действие `announcement`, компилятор обнаружит несовместимые типы.

<!-- lint-code-blocks: skip — намеренно соединяется строка с действием IO () -->
```text
brokenMessage = "Status: " ++ announcement
```

Для этого определения GHC сообщает об ошибке во втором аргументе `++`. Ключевой фрагмент сообщения выглядит так.

```text
    • Couldn't match expected type: [Char]
                  with actual type: IO ()
    • In the second argument of ‘(++)’, namely ‘announcement’
```

Ожидаемый тип `[Char]` совпадает со знакомым `String`. Фактический тип `IO ()` принадлежит действию `announcement`. При исполнении это действие выведет сообщение и вернёт `()`. Операция `++` работает со строками и не исполняет действия.

Для сообщения с префиксом сначала соединим строки, затем передадим полученный текст в `putStrLn`.

```haskell
statusAnnouncement :: IO ()
statusAnnouncement = putStrLn ("Status: " ++ statusMessage True)
```

В этом определении оба аргумента `++` имеют тип `String`. Функция `putStrLn` получает готовое сообщение и строит действие типа `IO ()`. При исполнении `statusAnnouncement` в консоли появится строка `Status: Device ready` с переводом строки в конце.
