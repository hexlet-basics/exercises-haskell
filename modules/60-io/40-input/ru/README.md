В этом уроке мы изучим чтение строки через `getLine`. Разберём связывание результата действия через `<-` и локальные определения `let` внутри `do`. Мы научимся передавать полученный текст чистой функции и выбирать ответ по результату проверки.

До сих пор исходные данные появлялись в аргументах функций или готовых определениях. Для программы, которая отвечает на введённый текст, источник данных находится снаружи. Чтение относится к взаимодействию с внешним миром, поэтому оно описывается действием `IO`.

## Строка как результат действия

В `Prelude` доступно действие `getLine` с типом `IO String`. При исполнении оно читает одну строку стандартного ввода и предоставляет её содержимое. Завершающий перевод строки в полученный `String` не входит. Если пользователь сразу завершил строку нажатием Enter, результатом будет пустая строка `""`. Пробелы внутри строки и по её краям сохраняются.

Для дальнейших действий текст нужно связать с именем. В блоке `do` запись `text <- getLine` задаёт исполнение действия справа и связывает его результат с именем слева. В следующих строках блока `text` имеет тип `String`, поэтому его можно передавать обычным функциям обработки текста.

Например, программа может прочитать сообщение и показать количество слов в нём. Сначала она получает текст, затем использует известные `words` и `length` для подсчёта.

```haskell
main :: IO ()
main = do
  text <- getLine
  putStrLn ("Words: " ++ show (length (words text)))
```

При вводе строки `Room is ready` программа выводит `Words: 3` и перевод строки. Пустая строка даёт вывод `Words: 0`. Имя `text` доступно после строки с `<-` до конца этого блока. Весь блок сохраняет тип `IO ()`, поскольку последнее действие `putStrLn` предоставляет результат `()`.

Схема показывает типы на пути от чтения до вывода.

```text
getLine :: IO String
          |
     text <- getLine
          |
    text :: String
          |
    length (words text) :: Int
          |
    putStrLn (...) :: IO ()
```

На этой схеме `getLine` имеет тип `IO String`, а имя `text` после `<-` имеет тип `String`. Чистое вычисление количества слов даёт `Int`, который используется для построения сообщения. Завершающее действие вывода имеет тип `IO ()`, как и весь блок `main`. Запись `<-` применяется здесь для результата действия `IO` и сама по себе не позволяет извлекать содержимое произвольного значения. Например, разбор `Maybe` по-прежнему выполняется через сопоставление с `Nothing` и `Just`.

## Локальные вычисления внутри do

Промежуточному чистому результату можно дать имя через `let`. Внутри `do` такое определение записывается без `in` и доступно следующим строкам блока. Подсчёт слов можно вынести в отдельную привязку.

```haskell
countMessageWords :: IO ()
countMessageWords = do
  text <- getLine
  let wordCount = length (words text)
  putStrLn ("Words: " ++ show wordCount)
```

Здесь `wordCount` имеет тип `Int`. Определение `let` связывает имя с чистым выражением и не читает дополнительную строку. Если написать `let action = getLine`, имя `action` получит тип `IO String`, поскольку справа находится само действие. Для его исполнения и использования полученного текста нужна строка с `<-` в блоке `do`.

## Проверка полученного текста

Выражение `case` может выбирать между действиями. Внутри `do` оно записывается на уровне соседних действий, а его ветви располагаются с дополнительным отступом. Например, программа может показать первое слово сообщения или сообщить, что слов нет.

```haskell
reportFirstWord :: IO ()
reportFirstWord = do
  text <- getLine
  let messageWords = words text
  case messageWords of
    [] -> putStrLn "No words"
    firstWord : _ -> putStrLn ("First word: " ++ firstWord)
```

В этом коде `case` начинается в той же колонке, что и `text <- getLine` и `let`. Образцы `[]` и `firstWord : _` выровнены между собой и сдвинуты глубже. Обе ветви выбирают `putStrLn` с типом `IO ()`, поэтому всё выражение `case` тоже имеет тип `IO ()`. Оно завершает блок `do` и определяет тип его результата.

Для строки `Room is ready` программа выводит `First word: Room` и перевод строки. Для пустой строки и строки из одних пробелов результатом вывода будет `No words` с переводом строки. Чистая функция `words` определяет содержимое списка, а сопоставление выбирает действие вывода для полученного варианта.

Чтение строки ещё не подтверждает пригодность её содержимого. Когда программа ожидает число, полученный `String` можно передать `readMaybe` с ранее изученной аннотацией `Maybe Integer`. Неверная запись даст `Nothing`, а распознанное число появится в `Just`. Отдельная чистая проверка определяет, подходит ли это число задаче.

Показанный способ выбора действия работает и с результатами проверки типа `Maybe` или `Either`. Неверный ввод при таком устройстве становится обычным результатом чистой функции, для которого программа заранее описывает ответ.

В этом уроке окружение предоставляет одну строку. Обработка конца ввода и повторный запрос требуют дополнительных решений и здесь не рассматриваются. Действия ввода описаны в [главе 7 Haskell 2010 Report](https://www.haskell.org/onlinereport/haskell2010/haskellch7.html), а синтаксис `do` в [разделе 3.14 главы 3](https://www.haskell.org/onlinereport/haskell2010/haskellch3.html).
