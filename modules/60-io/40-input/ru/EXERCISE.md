Реализуйте действие `main :: IO ()`, которое читает одну строку с количеством и выводит результат проверки. Используйте `getLine`, свяжите полученную строку с именем через `<-` и сохраните результат готовой чистой функции `parseQuantity` в локальном определении `let` внутри `do`.

Функция `parseQuantity :: String -> Either String Integer` уже написана в файле. Она применяет `readMaybe` для типа `Integer` и проверяет диапазон от `1` до `100` включительно. Изменять её не нужно. При неверной записи она возвращает `Left "Invalid integer"`, при числе вне диапазона возвращает `Left "Quantity out of range"`, а при допустимом количестве возвращает `Right` с этим числом.

Разберите результат проверки через `case` и выведите одну строку.

- Для `Right quantity` выведите префикс `"Accepted: "` и число в обычной записи, полученной через `show`.
- Для `Left message` выведите префикс `"Rejected: "` и готовую причину из `message`.

Каждое сообщение заканчивается одним переводом строки. Приглашение ко вводу и другой дополнительный вывод не нужны.

Стандартный ввод гарантированно содержит ровно одну строку с завершающим переводом строки. Она может быть пустой или состоять из пробелов, тогда функция проверки вернёт `Left "Invalid integer"`. Обработка конца ввода и повторный запрос в задачу не входят.

Правила записи числа определяет готовая функция через `readMaybe`. Например, пробелы вокруг числа, ведущие нули, скобки и шестнадцатеричная запись допустимы. Строки `"+3"`, `"12.0"` и `"12x"` распознать как `Integer` не получится. Отрицательные целые распознаются, но выходят за допустимый диапазон количества.

В примерах ниже строки обозначены как значения Haskell, чтобы показать завершающий символ `\n`.

| Стандартный ввод | Стандартный вывод |
| --- | --- |
| `"12\n"` | `"Accepted: 12\n"` |
| `" 001 \n"` | `"Accepted: 1\n"` |
| `"0x10\n"` | `"Accepted: 16\n"` |
| `"101\n"` | `"Rejected: Quantity out of range\n"` |
| `"hello\n"` | `"Rejected: Invalid integer\n"` |
| `"\n"` | `"Rejected: Invalid integer\n"` |
