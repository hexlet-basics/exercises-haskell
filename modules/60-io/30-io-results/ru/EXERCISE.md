Реализуйте функцию `report :: Integer -> IO Bool`. Количество передаётся функции как аргумент. Действие должно вывести одну строку с началом `"Quantity: "` и исходным количеством, а затем предоставить логический результат его проверки.

Допустимым считается количество от `1` до `100` включительно. Для такого значения результат действия равен `True`. Для любого другого значения `Integer`, включая ноль и отрицательные числа, результат равен `False`.

Например, при исполнении `report 3` вывод должен содержать следующую строку с завершающим переводом строки.

```text
Quantity: 3
```

Результат этого действия равен `True`. Для `report 0` вывод содержит `Quantity: 0` с переводом строки, а результат равен `False`.

Выводите сообщение для каждого переданного количества, включая недопустимое. Число в сообщении должно сохраняться без изменения. Логический результат предоставьте через `pure` в последней строке блока `do`. Печатать сам результат проверки или дополнительные сообщения не требуется.
