Реализуйте функцию `applyTwice` с сигнатурой `(a -> a) -> a -> a`. Она принимает функцию преобразования и исходное значение. Примените преобразование к исходному значению, затем примените его ещё раз к полученному результату.

Параметр типа `a` во всех позициях означает один выбранный тип. Поэтому переданное преобразование должно принимать и возвращать значения этого типа. `applyTwice` должна работать с разными конкретными типами, включая числа, строки, логические значения и списки.

Для примеров определим два простых преобразования.

```haskell
addOne :: Integer -> Integer
addOne number = number + 1

addMark :: String -> String
addMark text = text ++ "!"
```

Ожидаемые результаты применения `applyTwice` показаны ниже.

```haskell
applyTwice addOne 5     -- 7
applyTwice addMark "Hi" -- "Hi!!"
applyTwice not True     -- True
```

Второе применение должно получать результат первого. Переданное преобразование считается определённым для обоих применений. Вывод на экран не требуется.
