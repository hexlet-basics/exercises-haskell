В этом уроке мы изучим функции как аргументы и результаты других функций. Разберём передачу именованной функции и запись её типа внутри сигнатуры. Мы научимся отделять переданное правило обработки от значений, к которым оно применяется.

Иногда несколько вычислений отличаются только одним правилом. Например, одну и ту же пару показаний можно проверить на достаточную температуру или на соблюдение верхней границы. Общую часть обработки удобно описать один раз, передавая нужную проверку отдельно.

Функция в Haskell тоже является значением. Её можно передать аргументом и вернуть из другого вычисления. Функция, которая принимает или возвращает функцию, называется функцией высшего порядка. Для такого использования достаточно обычного имени уже определённой функции.

## Передача правила обработки

Пусть два датчика передают целые показания температуры. Программа должна убедиться, что оба значения подходят одному правилу. Само правило вынесем в отдельную функцию `isWarm`, проверяющую нижнюю границу.

```haskell
isWarm :: Integer -> Bool
isWarm temperature = temperature >= 18

checkBoth :: (Integer -> Bool) -> Integer -> Integer -> Bool
checkBoth check first second = check first && check second
```

В этом коде `checkBoth` получает три аргумента. Первый аргумент `check` является функцией проверки. Остальные аргументы содержат два целых значения. В выражении результата `check` применяется к каждому значению, после чего `&&` объединяет логические результаты.

Применение `checkBoth isWarm 21 15` даёт `False`, поскольку второе показание меньше `18`. Для `checkBoth isWarm 21 18` получаем `True`. Передача самой функции показана на схеме.

```text
проверка isWarm  ----\
значение 21      ----- checkBoth ----> False
значение 15      ----/
```

На этой схеме правило и два показания являются отдельными входами. Имя `isWarm` передаёт функцию, которую затем применяет `checkBoth`. Выражение `isWarm 21` уже имеет другой смысл и тип. Оно обозначает результат одной проверки, то есть значение `Bool`.

Если вместо `isWarm` передать `isWarm 21`, первый аргумент `checkBoth` окажется логическим значением. Его тип не соответствует ожидаемой функции `Integer -> Bool`, и компилятор сообщит об ошибке типов.

## Скобки в сигнатуре

Сигнатура `checkBoth` начинается с `(Integer -> Bool)`. Скобки объединяют весь тип первого аргумента. Читатель видит, что этот аргумент сам принимает целое число и возвращает логическое значение. Дальше записаны типы двух числовых аргументов и окончательного результата.

Без скобок начальные `Integer -> Bool` читались бы как отдельные позиции общей цепочки аргументов. Поэтому при передаче функции скобки в её типе существенны. Само значение функции при передаче дополнительно упаковывать не требуется.

Теперь можно заменить правило, сохранив общую обработку пары. Например, введём проверку верхней границы.

```haskell
belowLimit :: Integer -> Bool
belowLimit temperature = temperature < 30
```

В этой функции результат зависит от другой границы. Для `checkBoth belowLimit 21 15` получаем `True`, а для `checkBoth belowLimit 21 35` результатом будет `False`. Определение `checkBoth` остаётся прежним. Оно применяет переданную функцию проверки к своим входным данным.

## Функция как результат

Чистая функция может выбрать готовое преобразование и вернуть его. Для выбора подойдут уже известные условные выражения. Например, измерению нужна поправка на одну единицу вверх или вниз.

```haskell
raise :: Integer -> Integer
raise value = value + 1

lower :: Integer -> Integer
lower value = value - 1

chooseAdjustment :: Bool -> (Integer -> Integer)
chooseAdjustment shouldRaise =
  if shouldRaise then raise else lower
```

В этом коде обе ветви `if` возвращают функцию типа `Integer -> Integer`. Сигнатура `chooseAdjustment` сообщает, что после логического аргумента результатом станет именно функция. Выражение `chooseAdjustment True` обозначает `raise`, а `chooseAdjustment False` обозначает `lower`.

Возвращённой функции можно дать локальное имя и применить её к значению.

```haskell
adjustReading :: Integer -> Integer
adjustReading reading =
  let operation = chooseAdjustment True
  in operation reading
```

Здесь `operation` обозначает выбранную функцию `raise`. Поэтому `adjustReading 12` даёт `13`. Выбор и применение описаны разными выражениями, но между ними передаётся обычное значение функции. Собственные способы создавать новые функции по ходу вычисления мы разберём далее.
