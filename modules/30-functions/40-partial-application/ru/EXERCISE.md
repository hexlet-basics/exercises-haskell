Реализуйте функцию `bindFirst :: (a -> b -> c) -> a -> (b -> c)`.

Функция получает операцию с двумя аргументами и значение для её первого аргумента. Она должна вернуть функцию, которая принимает второй аргумент и применяет исходную операцию к фиксированному первому аргументу и полученному второму.

Порядок аргументов должен сохраняться. Например, для проверки можно использовать такую операцию.

```haskell
difference :: Integer -> Integer -> Integer
difference first second = first - second
```

Если `subtractFromTwenty = bindFirst difference 20`, то `subtractFromTwenty 3` должно дать `17`, а `subtractFromTwenty 8` должно дать `12`. Значение `20` остаётся первым аргументом `difference` при каждом применении полученной функции.

Реализация должна быть общей для типов `a`, `b` и `c`. Эти типы могут различаться. Исходная операция может, например, получать строку и логическое значение, возвращая строку. Проверять или преобразовывать фиксированное значение не требуется.

Используйте частичное применение переданной операции. Возвращаемую функцию должно быть можно применять многократно к разным вторым аргументам.
