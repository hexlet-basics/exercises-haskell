В этом уроке мы изучим отбор элементов списка через `filter`. Разберём предикаты и связь логического результата проверки с попаданием элемента в результат. Мы научимся сохранять подходящие элементы в исходном порядке и сочетать отбор с преобразованием через `map`.

Для многих задач нужен список только тех элементов, которые соответствуют правилу. Например, из подписей можно выбрать достаточно короткие для узкой карточки. Само правило удобно записать функцией, которая принимает один элемент и возвращает `Bool`. Такая функция называется предикатом.

Для каждого элемента предикат отвечает на один вопрос. Значение `True` означает, что элемент подходит, а `False` означает, что его нужно пропустить. Предикат можно передать другой функции как правило отбора.

## Предикат для одного элемента

Пусть на карточке помещается подпись длиной не более четырёх символов. Для учебного примера все подписи состоят из обычных латинских букв и цифр. Проверка использует известную функцию `length`.

```haskell
isShort :: String -> Bool
isShort label = length label <= 4
```

В этой функции `isShort "A1"` даёт `True`, а `isShort "North"` даёт `False`. Предикат получает целую подпись как один элемент и проверяет её длину. Пустая строка имеет длину ноль и тоже соответствует этому правилу.

## Отбор списка

Функция `filter` принимает предикат и список. Её тип записывается как `(a -> Bool) -> [a] -> [a]`. Во всех позициях `a` обозначает один тип элементов. Результат имеет тот же тип `[a]`, что и исходный список. Длина полученного списка зависит от того, сколько элементов подходят предикату.

Используем `isShort` для обработки всех подписей.

```haskell
shortLabels :: [String] -> [String]
shortLabels labels = filter isShort labels
```

В этом коде первым аргументом `filter` является функция `isShort`. Вторым аргументом передаётся список подписей. Например, `shortLabels ["North", "A1", "West", "B", "West"]` даёт `["A1", "West", "B", "West"]`.

Схема показывает связь между исходным списком и результатом отбора.

```text
["North", "A1", "West", "B", "West"]
                   |
             filter isShort
                   v
     ["A1", "West", "B", "West"]
```

На этой схеме строка `"North"` пропущена из-за длины. Остальные строки сохраняют свои значения и взаимный порядок. Две одинаковые подписи `"West"` остаются двумя элементами. Правило проверяет каждое вхождение независимо.

Для пустого списка `filter` возвращает `[]`. Такой же результат получится, если ни один элемент не соответствует правилу. Когда подходят все элементы, получаем список с теми же значениями в том же порядке. Исходное значение списка сохраняется.

## Отбор и преобразование

У `filter` и `map` разные задачи. Предикат отбора возвращает `Bool` и определяет, какие исходные элементы останутся. Функция преобразования для `map` возвращает новые значения. Сопоставим их по результату.

| Функция | Что происходит с элементами | Длина результата |
| --- | --- | --- |
| `filter` | Подходящие значения сохраняются | Может уменьшиться |
| `map` | Каждый элемент преобразуется | Сохраняется |

Таблица показывает, что `filter` сохраняет сами выбранные значения, а `map` сохраняет количество элементов. Для оформления отобранных подписей понадобятся обе функции, поскольку задача включает выбор элементов и изменение их текста.

Для оформления карточки можно сначала выбрать короткие подписи, затем заключить выбранные значения в квадратные скобки. Правило оформления вынесем в отдельную функцию.

```haskell
withBrackets :: String -> String
withBrackets label = "[" ++ label ++ "]"

displayShort :: [String] -> [String]
displayShort labels = map withBrackets (filter isShort labels)
```

В этом коде выражение `filter isShort labels` задаёт список выбранных подписей. Именно этот список передаётся `map`. Поэтому `displayShort ["A1", "West", "B"]` возвращает `["[A1]", "[West]", "[B]"]`.

Скобки показывают, какое значение участвует во внешнем вызове. В общей форме `map transform (filter check values)` входом для `map` служит результат `filter`. Такая запись задаёт зависимость данных между вызовами и не требует завершить вычисление всего отобранного списка перед преобразованием его элементов.

Перестановка этих действий может изменить смысл проверки. Например, `filter isShort (map withBrackets ["A1", "West", "B"])` даёт `["[A1]", "[B]"]`. После оформления строка `"[West]"` имеет длину шесть и уже не подходит прежнему предикату. При составлении обработки важно решить, к каким данным относится правило отбора.
