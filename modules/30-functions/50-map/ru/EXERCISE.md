Реализуйте функцию `productCodes :: [(String, Integer)] -> [String]`. Она получает список пар с кодами товаров и ценами, затем возвращает список кодов.

В каждой паре первый компонент содержит код товара, второй цену в целых рублях. Входной список содержит от `0` до `100` пар. Код является строкой длиной не более `40` символов, в том числе пустой. Цена находится в диапазоне от `0` до `1000000` включительно.

Для каждой входной пары в результате должен находиться её код на той же позиции. Сохраняйте повторяющиеся коды. Цена не влияет на результат. Пустому входному списку соответствует пустой список кодов.

Примеры показывают сохранение порядка и повторений.

| Применение | Результат |
| --- | --- |
| `productCodes [("A1", 100), ("B2", 250)]` | `["A1", "B2"]` |
| `productCodes [("B2", 500), ("A1", 100), ("B2", 0)]` | `["B2", "A1", "B2"]` |
| `productCodes [("", 20)]` | `[""]` |
| `productCodes []` | `[]` |

Используйте `map` и известную функцию извлечения первого компонента пары. Не сортируйте и не проверяйте коды, в этой задаче требуется только преобразовать структуру данных. Выводить результат на экран не требуется.
