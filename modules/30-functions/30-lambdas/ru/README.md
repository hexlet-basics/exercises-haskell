В этом уроке мы изучим лямбды и замыкания в Haskell. Разберём запись анонимной функции и использование имён из окружающей области видимости. Мы научимся передавать короткие функции как значения и возвращать функции с заданными параметрами поведения.

Функция, передаваемая другой функции, иногда нужна только в одном выражении. Для неё можно сразу записать аргументы и правило вычисления результата. Такая запись называется лямбдой или анонимной функцией. У самой лямбды нет имени, но её можно передать как аргумент, применить к значению или связать с именем.

## Запись анонимной функции

Лямбда начинается с обратной косой черты `\`. Затем идут имена аргументов, стрелка `->` и выражение результата. Например, функция добавляет квадратные скобки к тексту.

```haskell
frame :: String -> String
frame = \text -> "[" ++ text ++ "]"
```

В этом коде справа от `=` находится значение функции. Лямбда принимает аргумент `text` и возвращает строку со скобками. Имя `frame` связано с этой функцией, поэтому применение `frame "check"` даёт `"[check]"`. Именованная запись `frame text = "[" ++ text ++ "]"` описывала бы такое же вычисление.

Функцию можно применить сразу, заключив лямбду в скобки. Выражение `(\text -> "[" ++ text ++ "]") "check"` тоже даёт `"[check]"`. Скобки выделяют функцию целиком, а строка после них является её аргументом.

## Передача лямбды

Анонимная функция особенно удобна в точке передачи другому вычислению. Например, общая функция подготовки заметок добавляет подпись `"Note: "` и принимает отдельное правило оформления самого текста.

```haskell
decorate :: (String -> String) -> String -> String
decorate format text = "Note: " ++ format text

framedNote :: String
framedNote = decorate (\text -> "[" ++ text ++ "]") "check"
```

В этом примере `decorate` получает лямбду как первый аргумент. Внутри `decorate` это значение доступно под именем `format`. Применение `format text` оформляет заметку, а результат `framedNote` равен `"Note: [check]"`. Отдельное имя для переданного правила здесь не требуется.

Лямбда может принимать несколько аргументов. Их имена записываются через пробел перед одной стрелкой. Например, функцию разности двух целых значений можно записать так.

```haskell
difference :: Integer -> Integer -> Integer
difference = \left right -> left - right
```

В этой функции `difference 12 5` даёт `7`. Имя `left` связано с первым аргументом, `right` со вторым. Между именами аргументов нет запятых, а результат после стрелки является обычным выражением.

## Использование внешних имён

Тело лямбды может использовать имя, определённое в окружающей области видимости. В учебном примере к строке дважды добавляется заданная начальная часть. Для повторного применения правила подходит функция `applyTwice`.

```haskell
applyTwice :: (a -> a) -> a -> a
applyTwice operation value = operation (operation value)

twicePrefixed :: String -> String -> String
twicePrefixed prefix text = applyTwice (\body -> prefix ++ body) text
```

В этом коде `twicePrefixed` получает начальную часть `prefix` и исходный текст. Переданная в `applyTwice` лямбда получает собственный аргумент `body`. Значение `prefix` она использует из внешнего определения `twicePrefixed`. Функциональное значение вместе с доступными ему внешними значениями называют замыканием.

Таблица показывает два применения этой лямбды внутри `twicePrefixed "Work: " "Review"`.

| Применение лямбды | Внешнее значение `prefix` | Аргумент `body` | Результат |
| --- | --- | --- | --- |
| Первое | `"Work: "` | `"Review"` | `"Work: Review"` |
| Второе | `"Work: "` | `"Work: Review"` | `"Work: Work: Review"` |

В этой таблице аргумент `body` для второго применения получается из результата первого. Внешнее значение `prefix` в обоих случаях остаётся одним и тем же. Поэтому результат `twicePrefixed "Work: " "Review"` равен `"Work: Work: Review"`. При другом внешнем аргументе `twicePrefixed "Home: " "Review"` результат равен `"Home: Home: Review"`.

Захват окружения не добавляет лямбде ещё один аргумент. В записи `\body -> prefix ++ body` её аргументом является только `body`. Имя `prefix` доступно благодаря области, в которой записана лямбда. Захваченное значение неизменяемо, поэтому повторное применение одного правила использует ту же начальную часть.

## Лямбда как результат

Функция может вернуть лямбду так же, как возвращает именованную функцию. В обоих случаях результатом является функциональное значение. Если в сигнатуре результат имеет тип `Integer -> Integer`, возвращаемая функция должна принимать целое число и получать из него целый результат.

Лямбда позволяет описать такое значение прямо в выражении результата. Имена, доступные из окружающей области видимости, продолжают определять его поведение. Это даёт возможность получить разные правила обработки, передавая внешней функции разные значения. Отдельное правило сохраняет своё поведение при повторных применениях.

Например, программа создаёт проверку показания для заданного диапазона. Границы передаются одной парой, а результатом становится функция, которая принимает отдельное показание и возвращает `Bool`.

```haskell
makeWindowCheck :: (Integer, Integer) -> (Integer -> Bool)
makeWindowCheck (lowerBound, upperBound) =
  \reading -> reading >= lowerBound && reading <= upperBound
```

В этом коде образец пары связывает имена `lowerBound` и `upperBound`. Выражение справа от `=` является лямбдой, поэтому именно функция становится результатом `makeWindowCheck`. Показание `reading` поступит при её дальнейшем применении, а обе границы она использует из внешней области.

Выражение `makeWindowCheck (18, 24)` создаёт проверку, которая для `20` даёт `True`, а для `30` даёт `False`. Проверка `makeWindowCheck (2, 8)` использует другие границы и для `20` даёт `False`. Каждое полученное правило сохраняет свои границы независимо от других правил.
