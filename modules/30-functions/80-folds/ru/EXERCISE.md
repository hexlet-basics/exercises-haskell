Реализуйте функцию `buildChain :: String -> [String] -> String`, которая собирает текстовую цепочку меток с заданным завершением.

Первый аргумент `ending` содержит завершающий фрагмент. Второй аргумент `labels` содержит список меток в нужном порядке. В результате после каждой метки должен находиться ровно один символ `>`, затем следуют остальные метки и в самом конце фрагмент `ending`.

Завершающий фрагмент добавляется ровно один раз. Перед ним остаётся разделитель последней метки. Для пустого списка результат равен самому `ending`, без добавочного разделителя. Пустые метки допускаются и тоже добавляют свой символ `>`. Если `ending` является пустой строкой, после последней метки остаётся завершающий `>`.

Список содержит от `0` до `100` меток. Каждая метка и завершающий фрагмент содержат от `0` до `40` символов. Их содержимое нужно сохранять без изменений, в том числе повторяющиеся метки и уже имеющиеся в строках символы `>`.

Примеры задают положение меток, разделителей и завершения.

| Применение | Результат |
| --- | --- |
| `buildChain "END" ["A", "B"]` | `"A>B>END"` |
| `buildChain "STOP" ["C", "A", "B"]` | `"C>A>B>STOP"` |
| `buildChain "END" []` | `"END"` |
| `buildChain "" ["A", "B"]` | `"A>B>"` |
| `buildChain "END" ["A", "", "B"]` | `"A>>B>END"` |

Используйте `foldr`, выбрав базовый результат и правило соединения метки с обработанным остатком. Выводить результат на экран не требуется.
